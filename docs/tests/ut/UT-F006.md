# 単体試験仕様書 F006（中島敦3作品追加）

## 試験方針

- `DD-F006.md`の`FUN-F006-001`〜`FUN-F006-017`を1件ずつ網羅する。
- DD-F006.mdの「再利用方針」節が明記するとおり、FUN 17件中10件（FUN-F006-001/005〜010/013/016/017）は既存関数をそのまま呼び出す設計であり、既存のUT-F002〜F005が同一関数を汎用入力（feature非依存の値）で既に網羅している。これら10件は本書で新規UTケースを追加せず、対応する既存テストファイルを引用して「既存テストでカバー済み」と明記する。F006固有の値（authorId `000119`・workId `000624`/`000621`/`001738`）での結合確認はUT-F006-018〜027としてIT-F006側（作品単位atomic受入・Catalog統合シナリオ等）で行うため、本書のUTレベルでは重複させない。
- 残る7件（FUN-F006-002/003/004/011/012/014/015）はfeature固有のexact値・新規モジュールであるため、UT-F003/UT-F005の粒度（正常・境界同値・異常系）を踏まえつつ過剰に複雑化しない範囲で新規UTケースを作成する。ETW常時監視・native guard起因の複雑な境界（UT-F005-019/022/023/043/047等）はF006では不採用のため対象外。
- caller供給のPASSや自己申告identityを信用せず、canonical原artifact・Approved文書・実体hashからoracleを再計算する。手動・目視・聴取を正式PASS条件に含めない。
