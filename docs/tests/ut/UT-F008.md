# 単体試験仕様書 F008（江戸川乱歩3作品追加）

## 試験方針

- `DD-F008.md`の`FUN-F008-001`〜`FUN-F008-017`を1件ずつ網羅する。
- DD-F008.mdの各FUN本文を実際に精査した結果、17件中7件（FUN-F008-001/007/008/009/013/016/017）は「新規コードなし」と明記され既存関数をそのまま呼び出す設計であり、既存のUT-F002〜F007が同一関数を汎用入力（feature非依存の値）で既に網羅している。これら7件は本書で新規UTケースを追加せず、対応する既存テストファイルを引用して「既存テストでカバー済み」と明記する。F008固有の値（authorId `001779`・workId `056648`/`056650`/`057193`）での結合確認はIT-F008側で行うため、本書のUTレベルでは重複させない。
- 残る10件（FUN-F008-002/003/004/005/006/010/011/012/014/015）はfeature固有のexact値・新規モジュール（`f008-baseline.ts`・`f008-source.ts`・`f008-acceptance.ts`・`f008-catalog.ts`・`f008-artwork.ts`）であるため、UT-F007の粒度（正常・境界同値・異常系）を踏まえつつ過剰に複雑化しない範囲で新規UTケースを作成する。ETW常時監視・native guard起因の複雑な境界（F005系）はF008では不採用のため対象外。
- caller供給のPASSや自己申告identityを信用せず、canonical原artifact・Approved文書・実体hashからoracleを再計算する。手動・目視・聴取を正式PASS条件に含めない。
- FUN-F008-006（長大候補分割）は、F007のorder12(2408文字)実測で確定した「約1335文字超でVOICEVOX synthesisがHTTP 500を返す」制約を根拠に、600文字閾値・句点分割の同一アルゴリズムをF008でも適用する。人間椅子・一人二役は候補文字数が小さくDOMAIN-F008.mdの概算上分割対象になり得ないが、Ｄ坂の殺人事件（発話文字概算10,962文字/82候補）は分割対象候補が実測で出現する可能性が高い。UT-F008-006はF007と同一の分割アルゴリズム（境界文字列非依存の汎用ロジック）を検証するため、分割発動の有無自体はfeature値に依存しない構造としてUTレベルで確認する。
