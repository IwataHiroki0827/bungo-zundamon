# 単体試験仕様書 F003（太宰治コンテンツ追加）

## 試験方針

- `DD-F003.md`の`FUN-F003-001`〜`FUN-F003-029`を各1ケース以上で網羅する。
- 正常系に加え、上限同値・上限超過、欠落・重複・改変、競合・process停止、path/reparse境界を固定fixtureで自動検証する。
- caller供給の`pass`や自己申告identityを信用せず、canonical原artifact・trusted coordinator記録・実体path/hashからoracleを再計算する。
- 手動・実機・目視・聴取を必須証跡に含めない。正式PASSはT-043でexact candidateへ結合する。
