# 単体試験仕様書 F007（森鴎外3作品追加）

## 試験方針

- `DD-F007.md`の`FUN-F007-001`〜`FUN-F007-017`を1件ずつ網羅する。
- DD-F007.mdの各FUN本文を実際に精査した結果、17件中7件（FUN-F007-001/007/008/009/013/016/017）は「新規コードなし」と明記され既存関数をそのまま呼び出す設計であり、既存のUT-F002〜F006が同一関数を汎用入力（feature非依存の値）で既に網羅している。これら7件は本書で新規UTケースを追加せず、対応する既存テストファイルを引用して「既存テストでカバー済み」と明記する。F007固有の値（authorId `000129`・workId `058126`/`045245`/`000689`）での結合確認はIT-F007側で行うため、本書のUTレベルでは重複させない。
- 残る10件（FUN-F007-002/003/004/005/006/010/011/012/014/015）はfeature固有のexact値・新規モジュール（`f007-baseline.ts`・`f007-source.ts`・`f007-acceptance.ts`・`f007-catalog.ts`・`f007-artwork.ts`）であるため、UT-F006の粒度（正常・境界同値・異常系）を踏まえつつ過剰に複雑化しない範囲で新規UTケースを作成する。ETW常時監視・native guard起因の複雑な境界（F005系のUT-F005-019/022/023/043/047等）はF007では不採用のため対象外。
- caller供給のPASSや自己申告identityを信用せず、canonical原artifact・Approved文書・実体hashからoracleを再計算する。手動・目視・聴取を正式PASS条件に含めない。
