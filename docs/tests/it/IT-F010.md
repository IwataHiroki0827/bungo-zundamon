# 結合試験仕様書 F010（梶井基次郎3作品追加）

## 1. 試験方針

F010の結合試験は、既存の汎用結合フロー（IT-F003・IT-F004・IT-F005・IT-F006・IT-F007・IT-F008・IT-F009の該当シナリオ）がgeneric batch pipelineとして既に検証済みである範囲は簡潔に引用し、F010固有の結合シナリオ（新規作者・3作品の順次atomic受入、v0.9.0固定baselineへのCatalog統合、既存8作者27作品との共存、gaiji要素検出の実発動（候補外1件）、長大候補分割の非発動確認、作品固有注記UIの3作品全件不在確認、新規5モジュールの結合）に絞って詳細化する。失敗時に旧公開（v0.9.0）と第三者変更を保護することを各シナリオの共通条件とし、手動確認を必須条件にしない。

F010はF009と構造上2点で異なり、いずれもF009の該当シナリオを単純転用しない。

- **IT-F010-006**は、F009（瓶詰地獄・死後の恋2作品で`official-content-warning`が表示される）のような**notice表示の陽性ケース**ではなく、3作品全てで`official-content-warning`が表示されず`dialogue-excerpt-scope`のみが表示される**notice不在（陰性）ケース**として設計する。
- **IT-F010-003**は、F009（死後の恋で長大候補分割が実発動する）のような**分割発動ケース**ではなく、F010実candidate（最大133文字）に対し分割ロジックが呼び出されず候補が単一のまま不変であることを確認する**分割非発動ケース**として設計する。
