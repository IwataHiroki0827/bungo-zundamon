# 結合試験仕様書 F008（江戸川乱歩3作品追加）

## 1. 試験方針

F008の結合試験は、既存の汎用結合フロー（IT-F003・IT-F004・IT-F005・IT-F006・IT-F007の該当シナリオ）がgeneric batch pipelineとして既に検証済みである範囲は簡潔に引用し、F008固有の結合シナリオ（新規作者・3作品の順次atomic受入、v0.7.0固定baselineへのCatalog統合、既存6作者21作品との共存、人間椅子・Ｄ坂の殺人事件2作品の作品固有注記(official-content-warning)同時UI結合、Ｄ坂の殺人事件の長大候補分割、新規5モジュールの結合）に絞って詳細化する。失敗時に旧公開（v0.7.0）と第三者変更を保護することを各シナリオの共通条件とし、手動確認を必須条件にしない。
