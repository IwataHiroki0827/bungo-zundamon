# 結合試験仕様書 F012

## 1. 試験方針

`mountBungoZundamon`（`src/main.ts`）へ公開Catalog実データ・記録用Audio adapter・memory storage・fake Cache Storageを注入し、
route lifecycle・お気に入り・オフライン保存を通して結合する。実装は`src/f012-integration.test.ts`。

## 2. 結合シナリオ

### IT-F012-001: 速度設定付き連続再生とroute切替停止 [DES-F012-001][DES-F012-004]

作者routeで速度1.5倍を選び、作品パネルの連続再生を開始する。音声終了で2台詞目が「連続再生 2/N」で再生され、Audioの速度が1.5倍であること。
お気に入りrouteへ移動すると連続再生が解除・停止し、速度設定はsession中保持されること。

### IT-F012-002: 共有リンクからの確認付き取り込み [DES-F012-002]

`?fav=v1:...#/favorites`で起動すると共有queryがURLから除かれ、確認sectionが件数を表示し、追加前のお気に入りは0件であること。
「お気に入りに追加する」で2件が専用keyへ保存され、route再訪後は確認sectionが再表示されないこと。

### IT-F012-003: トップの検索結果・今日の一台詞からのお気に入り登録 [DES-F012-003][DES-F012-005]

固定時刻で今日の一台詞の日付keyが一致し、検索結果のカードからお気に入り登録できること。作品パネルの初期open 0を維持すること。

### IT-F012-004: オフライン保存のお気に入り追従 [DES-F012-006]

有効化前は音声を取得せず、有効化で公開音声（実WAV、SHA-256照合）を1件保存し、お気に入り解除で保存音声が0件になること。

### IT-F012-005: CSPとstorage契約 [DES-F012-008]

`index.html`のCSPが`verifyCsp`を通過し、`worker-src 'none'`へ戻すと`CSP_DIRECTIVE_INVALID:worker-src`になること。
F012追加moduleを含む本番TypeScript sourceでお気に入りstorage契約（`scanFavoriteStorageContract`）がpassedであること。
