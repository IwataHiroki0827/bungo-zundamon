# 結合試験仕様書 F007（森鴎外3作品追加）

## 1. 試験方針

F007の結合試験は、既存の汎用結合フロー（IT-F003・IT-F004・IT-F005・IT-F006の該当シナリオ）がgeneric batch pipelineとして既に検証済みである範囲は簡潔に引用し、F007固有の結合シナリオ（新規作者・3作品の順次atomic受入、v0.6.0固定baselineへのCatalog統合、既存5作者18作品との共存、舞姫の作品固有注記(official-content-warning)のUI結合、新規5モジュールの結合）に絞って詳細化する。失敗時に旧公開（v0.6.0）と第三者変更を保護することを各シナリオの共通条件とし、手動確認を必須条件にしない。
