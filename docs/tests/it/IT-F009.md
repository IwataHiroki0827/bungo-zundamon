# 結合試験仕様書 F009（夢野久作3作品追加）

## 1. 試験方針

F009の結合試験は、既存の汎用結合フロー（IT-F003・IT-F004・IT-F005・IT-F006・IT-F007・IT-F008の該当シナリオ）がgeneric batch pipelineとして既に検証済みである範囲は簡潔に引用し、F009固有の結合シナリオ（新規作者・3作品の順次atomic受入、v0.8.0固定baselineへのCatalog統合、既存7作者24作品との共存、瓶詰地獄・死後の恋2作品の作品固有注記(official-content-warning)同時UI結合、死後の恋の長大候補分割の実発動、gaiji要素検出の実発動、新規5モジュールの結合）に絞って詳細化する。失敗時に旧公開（v0.8.0）と第三者変更を保護することを各シナリオの共通条件とし、手動確認を必須条件にしない。

### IT-F009-003: 権利観測から原典固定・gaiji検出・長大候補分割まで [DES-F009-004][DES-F009-005][DES-F009-015]
