# CHG-F005-027 bound active lease中System directory writeの固定診断

## 変更理由

GitHub Actions run `30522096558`はactive lease中directory writeのunbound固定診断を備えた状態で、`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_UNBOUND_WRITE_OTHER_KNOWN_PATH_CACHE_OTHER_DIRECTORY_BOUND_LEASE`により安全停止した。同じtemporary writeのtiming差で、cache directoryへのSystem write到着時にはactive leaseのFileObjectが既に結合済みとなる場合がある。

## 変更内容

- exact `CACHE_OTHER_DIRECTORY_BOUND_LEASE`を既存のactive lease中directory write固定13 stage診断へ接続する。
- directory候補6 stageを先行し、その完全候補後だけlease存在・phase・親path・binding・closed・Job escapeを段階評価する。
- bound leaseは固定`LEASE_BOUND`として診断できるが、`CANDIDATE`を含め認可は追加しない。
- 容量actual、候補保存、公開条件は変更しない。

## セキュリティ境界

既存のSystem PID 0/4、write、非0未結合の観測FileObject、既知cache directory、完了write非一致、active lease結合済みbucketを前提とする。生path・identity・FileObject・PID・sequence・QPCを出力せず、未知suffixはgeneric診断へ閉じる。

CHG-F005-027反映後のnative pinはProgram SHA-256 `8b7c9d2b3df3507f68513d7ad9f0dd94443c5058bbf7513d9077b4e08f50bb05`、output binary SHA-256 `6c3e7fccad53a89705c14b261c88d31e9ed9f10771d44e210f87e0ab7d8b347a`、75,028,316 bytesとする。

## 検証

- bound/unbound両bucketが同じ固定13 stage診断へ限定接続されることをsource構造で確認する。
- 固定13 stage、段階評価、未知suffix拒否、runner伝播、認可分岐不変を回帰する。
- native規則136件、対象回帰124件、型、ESLint、同一SHA再現build 2回、trace、差分検査、公開差分0をPASSした。
- 独立レビューはHigh/Medium/Low 0件であり、commit固定のhosted productionを再試験する。

## 承認

認可を変更しない診断接続であり、要求承認ゲートは設けない。固定stage取得と影響試験完了まで`in-review`を維持する。
