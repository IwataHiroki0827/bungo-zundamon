# CHG-F005-024 System directory write再結合候補の固定診断

## 変更理由

GitHub Actions run `30519553414`は`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_UNBOUND_WRITE_OTHER_KNOWN_PATH_CACHE_OTHER_DIRECTORY_NO_LEASE`で安全停止した。active leaseのない時点で、同一voice phase中に既知となったcache directoryへのSystem writeが遅延到着している。

## 変更内容

- exact `CACHE_OTHER_DIRECTORY_NO_LEASE`だけをsnapshot、current、identity、root owner、root activeの固定6 stageへ細分化する。
- root ownerは同一phase/path/native identityの`create` observationがroot worker PID・ProcessSequenceNumberに完全一致する場合だけ成立する。
- snapshot→current→identity→owner→rootの段階評価とし、上位不一致後に不要なfilesystem/process照合を行わない。
- 認可、容量actual、候補保存、公開条件は変更しない。

## セキュリティ境界

既存のSystem PID 0/4、write、非0かつ未結合FileObject、既知path、active lease非一致、完了write非一致、cache directory、leaseなしを維持する。生path・identity・PID・sequence・QPCを出力せず、`CANDIDATE`でも自動認可しない。

CHG-F005-024反映後のnative pinはProgram SHA-256 `b2395ccb62b29dab0f93dc61b31aa17549d031d47fd019ff0a45fdd834982dc0`、output binary SHA-256 `33ecaab409de6a76d906c27e205434e33bd4f863aa1170f83e5946a8ae2f1d95`、75,028,316 bytesとする。

## 検証

- 固定6 stageの優先順位、同一phase/root generation/identity owner、未知suffix拒否、runner伝播を検査する。
- native規則111件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。
- 独立レビューの初回Medium 1件とLow 1件を解消し、最終判定High/Medium/Low 0件をPASSした。hosted productionで固定stageを取得する。

## 承認

認可を変更しない診断追加であり、要求承認ゲートは設けない。固定stage取得と影響試験完了まで`in-review`を維持する。
