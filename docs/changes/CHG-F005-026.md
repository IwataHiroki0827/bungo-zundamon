# CHG-F005-026 active lease中System directory writeの固定診断

## 変更理由

GitHub Actions run `30520947829`はleaseなしdirectory write再結合を通過後、`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_UNBOUND_WRITE_OTHER_KNOWN_PATH_CACHE_OTHER_DIRECTORY_UNBOUND_LEASE`で安全停止した。次のtemporary write leaseが予約済みでFileObject未結合の時点に、同じcache directoryへのSystem writeが到着している。

## 変更内容

- exact `CACHE_OTHER_DIRECTORY_UNBOUND_LEASE`だけを、directory候補6 stageとleaseの存在・phase・親path・binding・closed・Job escapeを含む固定13 stageへ細分化する。
- directoryが完全候補の場合だけlease判定へ進み、同一phaseかつlease pathの親directory一致を要求する。
- Job escape照合はdirectory・phase・親path・unbound・openの上位条件が一致した後だけ実行する。
- 認可、容量actual、候補保存、公開条件は変更しない。

## セキュリティ境界

System PID 0/4、write、非0未結合FileObject、既知cache directory、active unbound leaseを前提とする。未知directory stageは`DIRECTORY_UNKNOWN`へ閉じ、生path・identity・PID・sequence・QPCを出力しない。

CHG-F005-026反映後のnative pinはProgram SHA-256 `fe219ac26b5fcab693c5f6d301ccd3d442f4db120c0b7bfaaf33b63829649198`、output binary SHA-256 `a2a79f95e086df2cfa929ec8d86f7a8bfdc33d8d0af73e3baa9645bb66df7696`、75,028,316 bytesとする。

## 検証

- 固定13 stage、directory優先、lease phase/親path/binding/closed/escape、未知値拒否、runner伝播を検査する。
- 初回独立レビューのMedium 1件（directory非候補でもleaseを先行評価）とLow 1件（runtime評価順の試験不足）を、段階returnとsource順序・Job照合1回のassertで解消した。
- native規則136件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、差分検査、公開差分0をPASSした。最終独立レビューはHigh/Medium/Low 0件である。
- commit固定のhosted productionを再試験する。
- Actions run `30522096558`ではunbound variantは再発せず、同じdirectory writeが`CACHE_OTHER_DIRECTORY_BOUND_LEASE`となった。診断能力とhosted回帰を完了したため、bound variantの接続をCHG-F005-027へ分離する。

## 承認

認可を変更しない診断追加であり、要求承認ゲートは設けない。hosted回帰で次のtiming variantまで安全停止したため`done`とする。
