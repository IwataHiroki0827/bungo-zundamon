# CHG-F005-032 System結合済みFileObjectのrename中lease path固定診断

## 変更理由

Actions run `31025643577`はCHG-F005-031のlease時間分類を通過し、`audio-renamed`後に`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_PROCESS_BOUND_FILE_OBJECT_REJOIN_LEASE_PATH`で安全停止した。FileObject snapshot、観測path、current identity、active phaseまでは一致しているが、active leaseのcurrent pathとの関係を区別せず認可できない。

## 予定変更

- `LEASE_PATH`だけを次の評価順で固定14 stageへ分類する。
  1. `PATH_MISSING`: pending rename targetがない。
  2. `TARGET_MISMATCH`: 観測pathがpending rename targetと一致しない。
  3. `RESERVATION_MISSING`: rename予約QPCがない、または非正値である。
  4. `RESERVATION_ORDER`: rename予約QPCがlease current-path予約QPC以下である。
  5. `BEFORE_LEASE_RESERVATION`: event QPCがlease予約QPC以下である。
  6. `AFTER_LEASE_RESERVATION`: event QPCがlease予約QPCより後かつrename予約QPC以下である。
  7. `LEASE_CURRENT_EXISTS`: rename後も旧lease current pathが存在する。
  8. `SNAPSHOT_MISSING`: lease snapshotがない。
  9. `SNAPSHOT_PATH`: lease snapshot pathがlease current pathと一致しない。
  10. `IDENTITY_MISMATCH`: lease snapshot identityが観測FileObject snapshot identityと一致しない。
  11. `BINDING_MISMATCH`: active leaseのFileObject bindingが観測FileObjectと一致しない。
  12. `LEASE_CLOSED`: active leaseのFileObjectがclosedである。
  13. `LEASE_ESCAPE`: lease workerがJob外で生存している。
  14. `CANDIDATE`: 上記をすべて通過した完全候補。診断専用であり認可しない。
- raw path、QPC、identity、FileObject値を出力しない。
- 認可・容量actual・候補保存・公開条件は変更しない。

`SystemBoundFileObjectRejoinStage`へevent QPCを渡し、既存のsnapshot/path/current identity/phase確認を通過して`LEASE_PATH`となった経路だけで上記helperを呼ぶ。各stageは先行条件を満たした場合だけ次のfilesystem inspectionまたはJob照会へ進む早期returnとし、旧`LEASE_PATH` suffixと未知suffixはTypeScript境界でgeneric failureへ閉じる。

## 影響範囲

`tm.json`と既存のFUN-F005-047実装経路から、`REQ-F005-012`、`REQ-F005-013`、`DES-F005-006`、`FUN-F005-047`、`UT-F005-047`、`IT-F005-005`、`QT-F005-008`を影響対象とする。
