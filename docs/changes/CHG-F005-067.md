# CHG-F005-067 parent Boundのactive lease完全binding診断

## 変更理由

CHG-F005-066 hosted run `31257356440` は全parent proofがledger Boundで停止した。既存active-directory handoffはunbound/OtherBound admissionを前提とし、Bound eventを接続するとactive lease bindingを破壊し得るため、認可せずactive leaseとの完全bindingとevent種別だけを固定する。

## 変更内容

全outer parent not-unboundかつ全inner Boundの場合だけ、production共有pure ruleへevent-global scalarを渡す。引数はcandidate count、eventName、event FileObject、active lease/phase/snapshotの存在・有効性、active lease FileObject/identity/path、phase一致、parent一致、予約後、ExactGeneration存在boolとする。candidate count 1..128、eventName write/setinfo、event FO非zero、active lease/phase/snapshot必須、active lease FO非zero、identity/path非空、active voice/phase instance一致、same parent、event after active reservationをこの順にvalidationし、違反はSTATE_CHANGEDとする。その後event FO不一致またはExactGeneration nullをbinding mismatch、両方一致をexactとする。ExactGenerationはactive lease tupleへevent-global exact1回評価する。

scalar exactかつeventName writeなら`...PARENT_BOUND_ACTIVE_LEASE_WRITE_ALL`、setinfoなら`...PARENT_BOUND_ACTIVE_LEASE_SETINFO_ALL`、binding不一致なら`...PARENT_BOUND_ACTIVE_LEASE_BINDING_MISMATCH_ALL`へ固定する。event-global結果をcandidateへbroadcastせず、MIXEDは設けない。候補生成、handoff、OtherBound admission/apply、semantic map、active lease、stateは一切変更しない。

旧`PARENT_BOUND_ALL`は互換のみ、新3 code追加で80から83へ同期する。

## 試験方針

- active lease完全bindingのwrite/setinfo各candidate count 1/2/128、event FO差・ExactGeneration nullのbinding mismatch、順序反転を固定する。
- validation優先順の各違反をSTATE_CHANGEDへ固定する。
- lookup exact1、後段到達0、OtherBound/admit/apply0、semantic/auth fingerprint、83 code、非公開、public/data不変を回帰する。
- native、固定target、Vitest、typecheck、ESLint、trace、repro2、独立受け入れ、hostedを実施する。

## 承認

既存snapshotの非破壊診断だけを追加するdesign-level変更で要求は変更しない。独立レビューと影響試験までin-reviewとする。

## 独立設計レビュー

初回H2/M1のhandoff案を撤回し非破壊診断へ変更、続くM2をevent-global scalar・validation優先表・MIXED廃止で是正した。最終H0/M0/L0でPASSした。
