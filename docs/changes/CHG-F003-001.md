## 変更理由

- 単一候補のcode point、duration、WAV予測は上限同値`pass`、+1`blocked`と明記する。

- 未校正またはstaleな推定profileは`blocked`と明記する。
- 独立編集判定ではtrusted authorization、task/run/nonce差、primary非開示、seal改変拒否を検証する。

- 作者画像はF002の既存humanReview互換とF003のmachineReview契約を分け、identity/run/image hash不一致を拒否する。
