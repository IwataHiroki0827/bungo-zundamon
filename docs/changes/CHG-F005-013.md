# CHG-F005-013 完了済みwriteの固定診断

## 変更理由

GitHub Actions run `30510939972`は`wav-validated`後、`CACHE_WAV_FILE_NO_LEASE`のSystem `SetInfo`で安全停止した。同一voice phaseで完了済みWAVへの遅延metadata eventか、未知WAVへのeventかを、raw pathやidentityなしで区別する必要がある。

## 変更内容

- voice phase内で完了したnative writeのrelative pathとnative identityを、最大128件の内部診断台帳へ保持する。
- leaseなしのunknown System `SetInfo`が完了済みpathへ一致した場合、現実体をsame-handle由来identityと再照合し、`DONE_ID`、`DONE_CHANGED`、`DONE_MISSING`の固定状態だけを既存bucket診断へ返す。
- voice phase開始・正常終了で台帳を消去する。128件到達後の新規pathは追跡せず`NO_LEASE`へ閉じ、write完了条件を変えない。
- System `SetInfo`の認可、ETW算入、容量、候補保存、公開条件は変更しない。

## セキュリティ境界

公開診断は従来の`NO_LEASE/BOUND_LEASE/UNBOUND_LEASE`と追加3状態だけとし、path、basename、identity、FileObject、sequence、QPC、例外message、Win32番号を含めない。未知状態は`NO_LEASE`へ閉じる。内部台帳は診断にだけ参照し、認可判定へ入力しない。

CHG-F005-013反映後のnative pinはProgram SHA-256 `7866240bc5b7f31da8c3ec21eaf20e8b25915b67efd514b6c87ea8b2046d87ae`、output binary SHA-256 `5bbfb72f12a699fb4cdcff07c99c53637a00cf311395a10b96535033143054ae`、75,020,124 bytesとする。

## 検証

- 完了identity一致、差替え、欠落、未知状態をpure ruleで検査する。
- 固定診断のvalidator/classifier/runner伝播、最大文字数、raw値拒否を検査する。
- native規則、対象回帰、型、ESLint、再現build、trace、独立レビュー後にhosted診断を再試験する。

2026-07-30に対象5 test file 124件、native規則52件、型検査、ESLint、再現build 2回、YAML、trace、差分検査がPASSした。voice限定、128件上限後の新規未追跡、既存path更新、phase境界clear、identity一致・差替え・欠落、未知状態の`NO_LEASE`縮退を実行試験した。Program SHA-256、binary SHA-256、bytesは上記pinへ一致し、`public/`と`data/`の差分は0件である。独立セキュリティレビューはHigh 0、Medium 0、Low 0でPASSした。
