# CHG-F005-040 late candidate最初不一致軸の固定診断

## 変更理由

commit `54d327bbdbf444974911158fb3ca33928189601c`のActions run `31201498649`は、T-070 production pipelineの`temporary-written`後に再度generic `F005_ETW_WRITE_COMPLETION_DRAIN_LATE_EVENT_AFTER_SEAL`で安全停止した。CHG-F005-039の固定診断により、late candidateは存在するが、`CompletedRetained parent`、別active lease、same parent、現在予約QPC後の全条件を同時に満たす候補はないことを確定した。どの軸が不一致かはまだ未確定である。

## 予定変更

### 1. event kind別の最初不一致bucket

late candidateごとに次の固定順で最初に不一致となる軸を選ぶ。broad candidate条件からevent kindは`write`/`setinfo`のどちらかに限定される。

1. `SEAL_NOT_COMPLETED_RETAINED`: seal stateが`CompletedRetained`でない。
2. `CURRENT_PATH`: event pathがseal current pathである。
3. `ACTIVE_LEASE_MISSING`: `pendingWriteLease`がない。
4. `ACTIVE_PARENT_MISMATCH`: active lease current pathの親とevent pathが一致しない。
5. `AT_OR_BEFORE_ACTIVE_RESERVATION`: event QPCがactive lease予約QPCと同値以前である。

上記を次の積集合による10 exact codeとする。省略した共通prefixは`F005_ETW_WRITE_COMPLETION_DRAIN_`である。

- event kind prefix: `LATE_DIAG_WRITE_`、`LATE_DIAG_SETINFO_`
- mismatch suffix: `SEAL_NOT_COMPLETED_RETAINED`、`CURRENT_PATH`、`ACTIVE_LEASE_MISSING`、`ACTIVE_PARENT_MISMATCH`、`AT_OR_BEFORE_ACTIVE_RESERVATION`

例として完全文字列は`F005_ETW_WRITE_COMPLETION_DRAIN_LATE_DIAG_WRITE_CURRENT_PATH`、`F005_ETW_WRITE_COMPLETION_DRAIN_LATE_DIAG_SETINFO_AT_OR_BEFORE_ACTIVE_RESERVATION`となる。全条件一致時はCHG-F005-039の100/102文字codeを維持する。`CompletedRetained`への遷移と同じlock内で`pendingWriteLease`はnull化され、次の予約は必ず新しいlease objectを作るため、先行3軸成立後の同一lease参照は到達不能である。この不変条件違反は新しい外部codeにせずgeneric LATEでfail-closeする。

### 2. 複数candidateの決定的集約

全条件一致candidateが1個でもあれば、CHG-F005-039のevent kind別codeを最優先で返す。完全一致がない場合だけ、全late candidateを同じ純粋規則で分類する。同一lease不変条件違反を1個でも含む場合はgeneric LATEを返す。それ以外はdistinct mismatch codeが1個ならそのcodeを返し、2個以上なら`F005_ETW_WRITE_COMPLETION_DRAIN_LATE_DIAG_WRITE_MIXED_CAUSES`または`F005_ETW_WRITE_COMPLETION_DRAIN_LATE_DIAG_SETINFO_MIXED_CAUSES`を返す。候補列挙順で先頭codeを選ばない。これにより追加は合12固定code、外部exact code集合は23から35となる。追加codeは最長81文字で、許容上限127文字以内である。

### 3. 認可・状態非変更

broad/epoch/exact候補、late candidate、selected seal、producer tuple、ledger/proof、retained handle、queue、semantic map、capacity、notice、Observation、seal、leaseは変更しない。診断後は従来と同じexact late拒否位置でthrowし、後段active lease認可へ進まない。raw path、QPC、FileObject、identity、handle、PIDはreply、annotation、journalへ追加しない。candidate保存、Pages公開、`public/`、`data/`条件は変更しない。

## 影響範囲

`tm.json`の`DES-F005-006`/`DES-F005-012`から、`REQ-F005-012`、`REQ-F005-013`、`FUN-F005-017`、`FUN-F005-047`、`UT-F005-017`、`UT-F005-047`、`IT-F005-005`、`QT-F005-008`、`QT-F005-009`、`T-070`、`T-113`、`T-114`を影響対象とする。

## 試験方針

- write/setinfoそれぞれで全5軸の単独最初不一致、全条件一致、同一bucket複数candidate、異なbucket複数candidateをproduction共有純粋規則で固定する。同一lease不変条件はproduction遷移と専用fixtureで到達不能を固定し、純粋規則への異常入力はgeneric LATEとする。
- late candidateの列挙順を反転しても同一codeとなること、完全一致candidateが1個でもある場合はCHG-F005-039 codeを返すことを確認する。
- 35 exact codeをnative reply、bridge、runner、workflowの抽出/annotationへ同期し、unknown/extra/exact 128文字をgeneric化する。
- native rules、関連Vitest、typecheck、ESLint、trace_check、再現build 2回、独立受入、`public/`・`data/`差分0件を確認する。
- 同一source SHAのhosted productionを実行し、固定不一致軸または`MIXED_CAUSES`を証拠化する。

## 承認

認可・state非変更の固定診断変更であり、要求承認ゲートは設けない。独立設計レビュー、実装、影響試験、hosted再観測まで`in-review`を維持する。

## 独立設計レビュー

初回レビューはHigh 0 / Medium 1 / Low 0であった。Mediumは、`SAME_LEASE`が`CompletedRetained`遷移時のnull化と次予約のnew object生成によりproduction経路で到達不能であり、外部の最初不一致軸として不適切という指摘である。軸から除外し、不変条件違反はgeneric LATEにfail-closeする設計へ是正した。再レビューはHigh 0 / Medium 0 / Low 0でPASSした。

## 実装結果

- exact late拒否位置の候補からimmutableな`LateEventDiagnosticCandidate`を作り、`AggregateLateEventFailureCode`で完全一致最優先、generic不変条件fail-close、distinct 1種、event kind別`MIXED_CAUSES`の順に決定的集約する。
- SAME_LEASE外部codeは追加せず、`CompletedRetained`直後の`pendingWriteLease = null`と次予約の`new PendingWriteLease`をproduction sourceの構造試験に結合した。
- native/TypeScriptの35 exact code集合は差分0、workflowは35 codeを全受理し、SAME_LEASE、unknown、extra、exact 128文字を全層で拒否する。
- native executable rules 493/493件、関連Vitest 4 files / 57件、typecheck、ESLint、trace_check、再現build 2回、`public/`・`data/`差分0件をPASSした。
- 独立受入はHigh 0 / Medium 0 / Low 0でPASSした。
- Program SHA-256は`57adea83b070090aa19393f742738bbb6c3e7d37bd55771d7cf920a987f54f64`、binary SHA-256は`3eb63d297172f6776925921895c233577aca4cb75d9d378e04ce59276e7c003f`、サイズは75,143,004 bytesである。
