# CHG-F012-001 service worker導入に伴うCSP `worker-src`の意図的な変更

## 経緯

F012のオフライン対応(REQ-F012-006/DES-F012-006)は同一originの`sw.js`をservice workerとして登録する。
F001以来の公開CSPは`worker-src 'none'`であり、登録がCSPで拒否されるため、オーナー指示に基づき変更する。

## 変更内容

- `index.html`: `worker-src 'none'` → `worker-src 'self'`(他のdirectiveは不変)。
- `scripts/release-checks.mjs`・`scripts/f002-security.mjs`: 必須CSP(`REQUIRED_CSP`)へ`'worker-src': ["'self'"]`を追加。
  これによりbuild verificationとF002 security判定は`worker-src`の欠落・`'none'`・追加source(`blob:`・外部origin・`*`)をいずれも違反とする。
- `scripts/f002-security.test.mjs`・`scripts/release-checks.test.mjs`: CSP fixtureへ`worker-src 'self'`を追加し、拒否caseを追加。
- `playwright.config.ts`: 既存specは`serviceWorkers: 'block'`。service worker受入は`tests/e2e/f012-offline.spec.ts`だけがallowで行う。

## セキュリティレビュー

FD-F012.md §3を参照。許可するworkerは同一originの固定`sw.js`だけで、scope外・別origin・GET以外の要求をservice workerは扱わない。
保存する音声は利用者の明示的有効化時だけで、公開Catalogのbytes・SHA-256一致を確認する。判定: 許容(High/Critical 0)。

## 検証

`npm run typecheck`・`npm run lint`・`npm test`・`npm run build`(build verification passed)・Chromium/Android相当のPlaywright(既存+F012 spec)。結果はRELEASE-F012-precheck.mdに記録する。
