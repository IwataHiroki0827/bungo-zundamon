# CHG-F004-002 deploy無効化失敗時の回復契約

## 発見

F004試験仕様の妥当性レビューで、postdeploy rollback経路のdeploy変数無効化自体が失敗、またはprocess停止した場合に「全経路で無効」と判定できないことを検出した。

## 変更

- 無効化完了をAPI応答ではなくread-back `false`で判定する。
- deploy有効化前にrelease journalを`deploy-disable-pending`へatomic write・file syncして先行準備する。
- 失敗・process停止時はpre-armed journalを残し、published遷移を禁止する。
- 別processから起動できる独立cleanup entrypointでjournal/identity/SHAを再検証し、無効化を冪等に再開する。
- fault解除前はpending、解除後にread-back `false`を確認しexpected SHA付きCASでreleaseを閉じる。
