# CHG-F005-016 完了write再結合拒否stageの固定診断

## 変更理由

GitHub Actions run `30513755494`はclosed lease誤分類を除いた後も`CACHE_WAV_FILE_DONE_ID`で安全停止した。完了write fallbackの完全条件のうち、QPC上限、FileObject binding等のどの条件が不一致かをraw値なしで特定する必要がある。

## 変更内容

- 完了write再結合の拒否理由を`AUTH_FAILURE`、`SYSTEM_PID`、`EVENT`、`FILE_OBJECT_ZERO`、`PHASE`、`BEFORE_RESERVATION`、`AFTER_COMPLETION`、`FILE_OBJECT_BINDING`、`CURRENT_MISSING`、`IDENTITY_MISMATCH`の固定10 stageへ分類する。
- 同一pathの完了write recordが存在し、再結合条件が不成立の場合に固定stageをfail-closed codeへ保存する。
- nativeからTypeScript classifier、runner safe `causeCode`まで、exact allowlistに一致するstageだけを伝播する。
- 完了write再結合の認可条件、ETW算入、容量、候補保存、公開条件は変更しない。

## セキュリティ境界

公開するのは固定10 stageだけで、path、identity、FileObject、PID、sequence、QPC、例外message、Win32番号を含めない。未知suffixは汎用固定codeへ閉じる。分類順は認可条件と同じで、診断結果を認可へ入力しない。

CHG-F005-016反映後のnative pinはProgram SHA-256 `f3c3a4fec6f6c52472aa86afeb29298dc9f54d9d8aa032a836af609b51d06d45`、output binary SHA-256 `0dc637a3555656f414234161b73c44af28adc2bcde782a4edb9e5df57b49831c`、75,024,220 bytesとする。

## 検証

- 固定10 stageを各単独不一致から生成し、正常tupleは拒否理由なしとなることをpure ruleで検査する。
- validator/classifier/runner伝播、未知suffix拒否、raw値非公開を検査する。
- TOCTOU再照合の旧11番目codeを`IDENTITY_MISMATCH`へ統合し、first-poisonが後続汎用codeに上書きされない構造を回帰試験で固定した。
- native規則76件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。独立レビュー最終判定はHigh/Medium/Low 0件である。
- hosted productionで固定stageを取得し、認可変更が必要な場合は別変更として判断する。

## 承認

認可挙動を変更しない診断補正であり、要求承認ゲートは設けない。原因特定と影響試験完了まで`in-review`を維持する。
