# CHG-F003-003: hosted buildで固定公開baseline履歴を取得

| 項目 | 内容 |
|---|---|
| 発生日 | 2026-07-26 |
| 起票契機 | F003リリース候補のGitHub Actions run 30203038864で固定commitを読めず、hosted buildが失敗 |
| レベル | design |
| 状態 | in-review |

## 変更理由

F003は公開済みF002の固定commit `84c985f382910216e381a96901f6fd569165a27e` をGit objectから読み、既存コンテンツが不変であることを検証する。ローカルの完全cloneではPASSしたが、Actionsの既定shallow checkoutには固定commitが存在せず、`PUBLISHED_BASELINE_MISMATCH`で停止した。

## tm.jsonによる影響範囲

起点は`DES-F001-016`である。直接影響は`FUN-F001-032`、`UT-F001-032`、`.github/workflows/pages.yml`、`scripts/release-checks.mjs`、`scripts/release-checks.test.mjs`、F003リリースタスク`T-044/T-047`である。要求の意味、公開コンテンツ、deploy権限と承認SHA拘束は変更しない。

## 変更内容

- Actions checkoutへ`fetch-depth: 0`を追加し、固定公開baseline commitを読める完全履歴を取得する。
- `persist-credentials: false`を維持する。
- workflow検証で`fetch-depth: 0`を必須化し、shallow checkoutへの退行を`CHECKOUT_HISTORY_INCOMPLETE`で拒否する。

## 完了条件

- `UT-F001-032`を含む全Vitest、typecheck、lint、build、trace_checkがPASSする。
- feature/F003のhosted buildが同一候補commitでPASSし、deploy jobがスキップされる。
