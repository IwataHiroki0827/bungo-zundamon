# CHG-F005-020 closed active lease再結合候補の固定診断

## 変更理由

GitHub Actions run `30516456345`は完了writeの2秒限定再結合を通過した後、現在のactive leaseに一致するSystem SetInfoを`ETW_SYSTEM_SETINFO_CORRELATION_LEASE_CLOSED`で安全停止した。closed後eventを許可する前に、snapshot、FileObject binding、現存identityが完全候補を満たすかを固定値だけで特定する必要がある。

## 変更内容

- reservation tuple一致後のclosed leaseを`SNAPSHOT_MISSING`、`FILE_OBJECT_BINDING`、`CURRENT_MISSING`、`IDENTITY_MISMATCH`、`CANDIDATE`の固定5 stageへ分類する。
- bindingはevent FileObjectが未結合、または同一pathかつlease snapshotと同一identityの場合だけ互換とする。
- nativeからTypeScript exact classifier、runner safe `causeCode`まで固定stageだけを伝播する。
- closed leaseを引き続きfail-closedとし、認可、容量actual、候補保存条件は変更しない。

## セキュリティ境界

分類前に`BIRTH_MISSING`、System PID 0/4、SetInfo、非0 FileObject、同一phase/予約path、予約後QPC、Job非escapeを完全照合する。公開するのは固定5 stageだけで、path、identity、FileObject、PID、sequence、QPCを含めない。`CANDIDATE`も診断値であり認可しない。

CHG-F005-020反映後のnative pinはProgram SHA-256 `1c1760e43c0a52cc5d069a2997497b154dc62cfed7b3d0b888ae446bfb49784d`、output binary SHA-256 `a730a42ce33a1d824d4fce672ab176ce0a1ed57e3d2000edc50f288e08355f4d`、75,024,220 bytesとする。

## 検証

- 固定5 stageを各単独条件から生成するpure ruleを検査する。
- exact validator/classifier/runner伝播、未知suffix拒否、raw値非公開を検査する。
- snapshot→binding→filesystem→identityの段階評価を固定し、native規則95件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。独立レビュー最終判定はHigh/Medium/Low 0件である。
- hosted productionで固定stageを取得し、認可変更が必要な場合は別変更として判断する。

## 承認

認可挙動を変更しない診断補正であり、要求承認ゲートは設けない。候補条件特定と影響試験完了まで`in-review`を維持する。
