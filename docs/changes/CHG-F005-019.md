# CHG-F005-019 完了後2秒限定再結合

## 変更理由

GitHub Actions run `30516000235`は500ms限定再結合後も`F005_ETW_COMPLETED_WRITE_REJOIN_AFTER_COMPLETION_WITHIN_2S`で安全停止した。hosted schedulingの揺らぎにより、同一WAV・同一native identityのSystem SetInfoが完了後500ms超2秒以内となる場合を確認した。

## 変更内容

- 完了write完全tupleの時間上限を、完了後500msからhosted実測済みの2秒へ拡張する。
- 同一QPC clock上で`eventTimestampQpc - completedAtQpc <= frequency * 2`を要求し、2秒ちょうどを許可、1 tick超過を拒否する。
- long減算前のdecimal昇格、`BIRTH_MISSING`、System PID 0/4、SetInfo、非0 FileObject、同一phase/path、互換binding、現存同一identity、認可後再照合を維持する。
- 認可eventの容量actual算入、voice phase最大128 path、phase終了clear、候補保存条件を変更しない。

## セキュリティ境界

2秒はhostedで観測した最小固定bucket上限であり、phase全体へ拡張しない。2秒超、別tuple、実体欠落、identity差替え、FileObject非互換は固定診断でfail-closedとする。時間条件単独では認可しない。

CHG-F005-019反映後のnative pinはProgram SHA-256 `21b938256ad8db43c0dde9edcb4a22d714d2ebeb4ebfbf6cc8a7422fa9b97c01`、output binary SHA-256 `9111bc196e50e613825bca855f1b58427ca8a9c0f521f9e11f9a9fa5be29e439`、75,024,220 bytesとする。

## 検証

- 完了QPC以前、完了後2秒上限、2秒+1 tick、不正frequency、long極値をpure ruleで検査する。
- 他9拒否stage、binding/identity二重照合、first-poison、capacity/candidate不変を回帰検査する。
- native規則90件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。独立レビュー最終判定はHigh/Medium/Low 0件である。
- hosted productionで2秒限定再結合後のidentity・容量・候補保存を再試験する。
- Actions run `30516456345`は完了write再結合を通過し、active lease側の`LEASE_CLOSED`で安全停止した。2秒境界の目的を達成し、closed lease診断はCHG-F005-020へ分離する。

## 承認

要求目的・容量停止基準・公開条件を変えない設計境界変更であり、要求承認ゲートは設けない。hosted影響試験を完了したため`done`とする。
