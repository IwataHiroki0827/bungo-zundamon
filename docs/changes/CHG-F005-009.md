# CHG-F005-009 native runtimeのguard対象外配置

## 変更理由

GitHub Actions run `30507414370`は`wav-validated`後、helper processを起動してartifact pathを予約する前に、workspace内`.cache/dotnet-f005/publish/f005-guard.exe`に伴うSystem `SetInfo`を観測して安全停止した。VOICEVOX runtimeは既に`RUNNER_TEMP`へ隔離済みだが、同一native binaryだけがguard対象workspace内から反復起動されていた。

## 変更内容

- pinned native build完了後、同一binaryを`RUNNER_TEMP`配下のGUID付き新規exclusive directoryへ複製する。
- 複製先がworkspace外、non-reparse、hardlink数1であることと、build evidenceのoutput SHA-256へ一致することをworkflowとruntimeの双方で再検証する。
- production runnerは`F005_NATIVE_GUARD_PATH`を正規化済みabsoluteかつworkspace外に限定し、容量guard、write-through helper、directory flush、acceptance用native clientの全起動経路へ伝播する。
- spawn直前にreal path、regular file、reparse、hardlink数、固定SHAを再検証し、起動したnative process自身が`hello.binarySha256`へ実行中imageのSHA-256を返す。全clientは固定pinとの一致を必須とする。
- workspace内binaryとbuild evidenceは再現build検証用に保持し、source treeを変更しない。

## セキュリティ境界

外部配置を理由にbinary trustを緩和しない。relative、workspace内、非正規化path、symlink/junction/reparse、hardlinkをproduction runnerで拒否する。検査からspawnまでの差し替えはspawn直前検査と実process image由来のself hashで検出する。guard対象から外すのは固定SHAのtooling executableだけで、candidate/audio/staging pathは従来のworkspace root内ETW監視を維持する。

CHG-F005-009反映後のnative pinはProgram SHA-256 `1ce9ca9e957fd28862648c8496b502b1afaf4cee554ae64629ffa21e97a52716`、output binary SHA-256 `08899bced4e40b2c8c615a840b943b14389a0b246f09b1ce540c5bad18f90bb1`、75,016,028 bytesとする。

## 検証

- override未指定、workspace外absolute、workspace内、relative、hardlink、junctionのケースを検査する。
- workflowのGUID付きexclusive directory、outside/reparse判定、copy後SHA、step outputとproduction env結合を静的検査する。
- native実機試験で`hello.binarySha256`がbuild evidenceのoutput SHAと一致することを検査する。
- 型検査、対象回帰、独立セキュリティレビュー後にhosted正常系を再試験する。

2026-07-30に型検査、ESLint、対象5 test file 124件、native相関規則37件、再現build 2回、差分検査がPASSした。Program SHA-256、binary SHA-256、bytesは上記pinへ一致し、`public/`と`data/`の差分は0件である。独立セキュリティレビューはHigh 0、Medium 0、Low 0でPASSした。

## 承認

要求内容を変えないtooling配置補正であり要求承認ゲートは設けない。hosted正常系が完了するまで`in-review`を維持する。
