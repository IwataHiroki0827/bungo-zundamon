# CHG-F002-006 mainベース別ブランチでの規約再確認期限廃止（PR #3）

## 変更理由

`content/licenses.json` の `validUntil`（2026-08-18）が失効した。
Q-048/Q-049の経緯で、プロジェクトオーナーは「暦に基づく期限という概念そのものを廃止する」を
既に選択・承認している（詳細な理由・トレードオフはCHG-F002-005を参照）。

今回、オーナーへ改めて確認した結果、この承認済みの決定を、
`feature/F005` ブランチとは独立に、**main（v0.4.0）を起点とする別ブランチ**
`fix/v0.4.1-license-recheck` で実装した。

対象コードはF005ブランチ側の実装と完全には一致しない。
F005ブランチ側（CHG-F002-005）は `src/notices/credits.ts` の `validUntil` 判定に加え、
F005作業中に追加された `scripts/verify-project.mjs` の `verifyLicenseTermsFreshness` も削除している。
一方、本エントリの対象は main 側に元々存在するコードであり、
`src/notices/credits.ts` の `validUntil` 判定に加えて、
F001由来の `src/notices/release-notices.ts` の `terms-expired` 判定も削除している
（`verifyLicenseTermsFreshness` はF005固有の追加のためmain側には存在しない）。

## 変更内容

- `src/notices/release-notices.ts` — F001由来の `terms-expired` 判定を削除
- `src/notices/credits.ts` — `validUntil` の解析・比較を削除、有効期限の表示を削除
- `src/notices/notices.test.ts` — 上記削除に対応するテストを更新

`content/licenses.json` / `public/content/licenses.json` は変更しない。
凍結されたF001 baseline・固定定数・固定commitも変更しない。

## 承認

要求レベル変更のため承認ゲートを必須とする。
Q-049でプロジェクトオーナーが「期限の概念そのものを廃止する」を選択し承認済み（CHG-F002-005と共通）。

## F005ブランチ側の同一決定との関係

`feature/F005` ブランチには既にcommit `8c0e320`（2026-08-19）で同種の実装
（CHG-F002-005、`docs/changes/changes.yaml` 未登録）が存在する。
本エントリはそれとは**独立した実装**であり、CHG-F002-005を上書き・置換するものではない。
F005が将来mainへマージされる際、同じ意図の重複削除により軽微なコンフリクトが
発生しうる（STATUS.mdの次のアクションを参照）。

CHG-F002-005の `changes.yaml` への正式登録は本エントリのスコープ外であり、対応していない。
