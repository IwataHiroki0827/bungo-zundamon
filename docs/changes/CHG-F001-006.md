# CHG-F001-006: 作者ページの作品を初期状態で全件閉じる

| 項目 | 内容 |
|---|---|
| 発生日 | 2026-07-26 |
| 起票契機 | プロジェクトオーナー直接指示 |
| レベル | requirement |
| 状態 | done |

## 変更理由

作者ページへ遷移した直後に収録作品の先頭だけが自動展開され、一覧全体を見渡しにくかった。旧表示とCatalogV2表示が同じ自動展開を持ち、単体試験とブラウザ試験もその挙動を固定していたため、全作者routeの初期状態を閉じた状態へ統一する。

## tm.jsonによる影響範囲

起点は`REQ-F001-004`である。直接影響は`DES-F001-010`、`FUN-F001-023`、`UT-F001-023`、`IT-F001-010`、`QT-F001-002`。CatalogV2の再利用経路として`FUN-F002-023`、`UT-F002-023`、`IT-F002-010`、`QT-F002-002`、F003の作者route設計・自動受入として`REQ-F003-003`、`DES-F003-009`、`DES-F003-011`、`FUN-F003-026`、`UT-F003-026`、`IT-F003-010`、`QT-F003-015`、`T-036`へ波及する。公開データ、音声、権利・由来artifactには影響しない。

## 変更内容

- 作者ページ描画時は先頭を含む全`details.work-panel`から`open`属性を除く。
- 直接遷移、トップからの遷移、再読込、作者切替の各初期表示で全作品を閉じる。
- 利用者が`summary`をpointerまたはキーボードで操作した場合だけ作品を展開する。
- 旧表示とCatalogV2表示で同じ共通描画関数を使用し、作者固有分岐を追加しない。

## 承認

本会話の「最初は閉じるようにしておいて」というプロジェクトオーナーの直接指示を要求変更の承認として`Q-019`へ記録した。

## 完了結果

- 共通`renderWork`から初期展開引数を除去し、全作者routeの初期状態を閉じた。
- 単体試験とPlaywright試験を、初期全閉・キーボード展開の回帰試験へ更新した。
- 自動試験結果は本変更コミット前の検証として記録し、F003の正式candidate試験はT-043で再実施する。
