# CHG-F005-012 System SetInfo相関段階の固定診断

## 変更理由

GitHub Actions run `30510118610`はCHG-F005-011の固定bucket判定を通過し、予約済みwrite pathに対するSystem `SetInfo`を認識した後、`F005_ETW_SYSTEM_SETINFO_CORRELATION_MISMATCH`で安全停止した。認可を緩める前に、snapshot、FileObject、遅延tuple、identity、cleanupのどの固定条件が不一致かをraw値なしで特定する必要がある。

## 変更内容

- 汎用相関不一致を、`CREATE_BIND_MISMATCH`、`CREATE_SNAPSHOT_MISSING`、`CURRENT_MISSING`、`DEFERRED_BIND_MISMATCH`、`DEFERRED_CLEANUP`、`DEFERRED_SNAPSHOT_MISSING`、`DEFERRED_TUPLE_MISMATCH`、`FILE_OBJECT_MISMATCH`、`IDENTITY_MISMATCH`、`LEASE_CLOSED`、`LEASE_SNAPSHOT_MISSING`、`RENAME_CONSUME`の固定12段階へ分割する。
- native replyからrunnerの`causeCode`まで、上記allowlistに完全一致する値だけを伝播する。
- 相関、ETW算入、容量、候補保存、公開条件は変更しない。

## セキュリティ境界

公開診断は固定12段階だけとし、path、FileObject、identity、sequence、QPC、例外message、Win32番号を含めない。未知suffixはrunnerで拒否し、汎用固定codeへ閉じる。分類は診断専用で認可判定へ入力しない。

CHG-F005-012反映後のnative pinはProgram SHA-256 `89f68ea6f2daa7e839be9c23dc18fa8db56c4c913900c2eea8d6e3aa2947149f`、output binary SHA-256 `8062d2e92a8e7c852e49d641c863b16b3159bd6104c9ac4dc84acb9ff050a128`、75,020,124 bytesとする。

## 検証

- 固定12段階の分類、runner伝播、未知suffix拒否を検査する。
- source上の主要相関分岐が個別codeを返し、従来の認可条件を変更しないことを検査する。
- native規則、対象回帰、型、ESLint、再現build、trace、独立レビュー後にhosted診断を再試験する。

2026-07-30に対象5 test file 124件、native規則40件、型検査、ESLint、再現build 2回、YAML、trace、差分検査がPASSした。nativeの固定12段階とTypeScript allowlistは集合一致し、未知suffixは汎用固定codeへ閉じる。全Vitest 1270件の同時実行ではWindows並列I/O負荷により7件がtimeoutしたが、変更対象とtimeout対象を隔離再実行した188件は全件PASSし、機能アサーション失敗は0件である。Program SHA-256、binary SHA-256、bytesは上記pinへ一致し、`public/`と`data/`の差分は0件である。独立セキュリティレビューはHigh 0、Medium 0、Low 0でPASSした。
