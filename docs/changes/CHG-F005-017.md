# CHG-F005-017 完了後再結合の時間差固定bucket診断

## 変更理由

GitHub Actions run `30514533508`はCHG-F005-016の固定診断により`F005_ETW_COMPLETED_WRITE_REJOIN_AFTER_COMPLETION`で安全停止した。同一WAV・同一native identityのSystem SetInfoがwrite完了QPCより後であることは判明したが、許容可能性を判断するための時間差は未確定である。

## 変更内容

- `AFTER_COMPLETION`を、完了後`WITHIN_100MS`、`WITHIN_500MS`、`WITHIN_2S`、`WITHIN_10S`、`OVER_10S`の固定5 bucketへ細分化する。
- ETW `TimeStampQPC`と`Stopwatch.GetTimestamp()`の同一QPC clock上の差だけを使い、raw QPC、周波数、実時間、path、identity等は公開しない。
- nativeからTypeScript exact classifier、runner safe `causeCode`まで固定bucketだけを伝播する。
- 完了QPC上限を含む再結合認可条件、ETW算入、容量、候補保存、公開条件は変更しない。

## セキュリティ境界

固定5 bucketは診断専用であり、認可幅へ自動変換しない。hosted実測後も、時間上限、FileObject lifecycle、同一phase/path/identity、次write予約との境界を別変更で再評価する。未知bucketと値付きsuffixは汎用固定codeへ閉じる。

CHG-F005-017反映後のnative pinはProgram SHA-256 `99d9241538695ea47d75fffbaea31f187128a7b97f39bd1e65b84af61cab18be`、output binary SHA-256 `464f30b5fabf0220d7b5a45762fb8d14a6890c9e4eab5fff1316da4c03c3e432`、75,024,220 bytesとする。

## 検証

- 100ms、500ms、2秒、10秒の各境界と10秒超をpure ruleで検査する。
- exact validator/classifier/runner伝播、未知suffix拒否、raw値非公開を検査する。
- 各境界上限と1 tick超過を含むnative規則84件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。独立レビュー最終判定はHigh/Medium/Low 0件である。
- hosted productionで固定bucketを取得し、認可変更が必要な場合は別変更として判断する。
- Actions run `30515251601`で`WITHIN_500MS`を取得し、目的を達成した。限定再結合はCHG-F005-018へ分離する。

## 承認

認可挙動を変更しない診断補正であり、要求承認ゲートは設けない。固定bucket取得と影響試験を完了したため`done`とする。
