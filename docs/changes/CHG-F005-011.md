# CHG-F005-011 unknown System SetInfoの固定診断細分化

## 変更理由

GitHub Actions run `30509193028`はnative executableとcwdをworkspace外へ隔離した後も、`wav-validated`後にSystem `SetInfo`のunknown workspace pathを観測して安全停止した。認可を緩める前に、遅延metadata eventの対象種別とwrite lease状態をraw pathなしで特定する必要がある。

## 変更内容

- System PID 0/4、unbound FileObject、unknown pathの固定失敗codeへ、top-level bucket、extension bucket、実体状態、write lease状態を付加する。
- 各bucketは固定allowlistへ写像し、未知値は`OTHER`へ閉じる。raw path、basename、Win32番号、例外messageは出力しない。
- 容量認可、ETW算入、候補保存条件は変更しない。

## セキュリティ境界

top-levelは`CACHE/CONTENT/DATA/DIST/NATIVE/NODE_MODULES/PUBLIC/SCRIPTS/SRC/OTHER`、extensionは`EXE/JS/JSON/LOG/TMP/TS/WAV/OTHER`、実体は`FILE/DIRECTORY/ABSENT`、leaseは`NO_LEASE/BOUND_LEASE/UNBOUND_LEASE`だけを公開する。分類は診断専用で、認可判定へ入力しない。

CHG-F005-011反映後のnative pinはProgram SHA-256 `d0d72b78807988d4499b2b9677dfb260e60fc0bee5220eaa9bda55577fbcdf82`、output binary SHA-256 `729aeae844236467016f060fec5b7799c61aec14923f7d07bbc5f024a4ecf1a4`、75,016,028 bytesとする。

## 検証

- allowlist内、未知bucket、FILE/DIRECTORY/ABSENT、lease 3状態のpure ruleを検査する。
- 既存の固定診断正規表現へ収まり、raw pathが出力されないことを検査する。
- native規則、対象回帰、型、ESLint、再現build、独立レビュー後にhosted診断を再試験する。

2026-07-30に対象5 test file 124件、native規則40件、型検査、ESLint、再現build、YAML・差分検査がPASSした。dynamic codeはnative classifierからrunner safe failureまで固定値のまま到達し、最大case 126文字、SETINFO以外の従来code維持、invalid bucket/path/stateの汎用化を自動試験した。Program SHA-256、binary SHA-256、bytesは上記pinへ一致し、`public/`と`data/`の差分は0件である。独立セキュリティレビューはHigh 0、Medium 0、Low 0でPASSした。

## 承認

要求内容と認可挙動を変えない診断補正であり、要求承認ゲートは設けない。原因特定と影響試験完了まで`in-review`を維持する。
