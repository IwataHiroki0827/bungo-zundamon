# CHG-F005-068 active-bound parent validation軸診断

## 変更理由

run `31258105374` attempts 1/3はSTATE_CHANGED、attempt2はACTIVE_LEASE_BINDING_MISMATCH_ALLで停止した。CHG067 pure ruleの非公開validation軸を固定分離する。

## 変更内容

既存評価順を変えず、count/event/eventFOの不正はSTATE_CHANGEDを維持する。以降を、lease/phase/snapshot欠落=`CONTEXT_MISSING`、lease FO/identity/path不正=`TUPLE_INVALID`、voice/phase instance不一致=`PHASE_MISMATCH`、parent不一致=`PARENT_MISMATCH`、予約順不正=`RESERVATION_ORDER`、event FO差=`EVENT_FO_MISMATCH`、ExactGeneration null=`LEDGER_MISSING`へ固定する。exact write/setinfoは既存codeを維持する。

codeは共通prefix `...POST_UPPER_PROOF_PARENT_BOUND_` に上記suffixを付け、生値・件数を含めず127文字以内とする。旧STATE_CHANGED/BINDING_MISMATCH_ALLは互換・他経路に残し、新7 code追加で83から90へ同期する。handoff/OtherBound/admit/apply/semantic/stateは変更しない。

## 試験方針

各軸単独・複合の優先順、境界、候補順、ExactGeneration exact1、後段0、90 code、非公開、semantic/auth/public/data不変と全回帰・hostedを検査する。

## 承認

非破壊診断のみのdesign-level変更。独立レビューと影響試験までin-review。

## 独立設計レビュー

High 0 / Medium 0 / Low 0でPASS。優先順、90 code、非破壊性に残指摘なし。
