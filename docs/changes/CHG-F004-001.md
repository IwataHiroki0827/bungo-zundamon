# CHG-F004-001 お気に入り機能の追加

## 変更理由

プロジェクトオーナーから「お気に入り機能が欲しいね」と直接要望を受けた。F004は設計着手時点で実装・試験成果物が未作成であり、台詞の安定IDとCatalogを利用する本機能を同じ公開候補へ含めることが、後付け変更よりも小さい影響で実現できる。

## 変更内容

- 全公開台詞へ、お気に入り登録・解除操作を追加する。
- version付き専用localStorage keyへ端末内保存し、外部同期・アカウント・追跡は行わない。
- `#/favorites`で作者をまたいだ登録台詞をCatalog順に表示する。
- 破損、未知version、書込失敗、Catalogから消えたIDをfail-safeで処理する。
- 公開スモーク対象を5 routeから6 routeへ更新する。

## 影響範囲

- `REQ-F004-001`、`REQ-F004-017`〜`REQ-F004-021`
- `QT-F004-001`、`QT-F004-013`〜`QT-F004-016`
- `FD-F004.md`、`DD-F004.md`
- `UT-F004.md`、`IT-F004.md`
- T-051、T-052、T-053、T-055、T-059、T-060、T-061、T-062
- route、dialogue UI、audio controller、Catalog join、localStorage境界、CSP/外部通信検査、公開route allowlist

## リスクと対策

- 保存値を信頼してDOMへ挿入しない。IDだけを受け取り、現行Catalogへjoinしたtext nodeだけを描画する。
- key・schema version・最大件数を固定し、不正値は破棄する。
- localStorage不能時も閲覧・再生を止めず、当該セッションのメモリ状態へ縮退する。
- お気に入り操作と音声操作を分離し、意図しない自動再生を防ぐ。
