# CHG-F005-022 System未結合write既知pathの固定診断

## 変更理由

GitHub Actions run `30517951376`はclosed active lease完全候補の限定再結合を通過後、`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_PROCESS_UNBOUND_FILE_OBJECT_WRITE_KNOWN_PATH`で安全停止した。System PID 0/4のwriteが既知pathへ届いたことだけでは、active lease、完了write、無関係pathのいずれかを安全に判別できない。

## 変更内容

- System PID 0/4、FileObject未結合、write、既知pathの既存停止経路だけを固定10 stageへ細分化する。
- `FILE_OBJECT_ZERO`を最優先し、同一phase/pathのactive leaseはsnapshot、current、identity、open/closed候補の順で分類する。
- active lease非一致時は完了write台帳の`COMPLETED_ID/CHANGED/MISSING`または`OTHER_KNOWN_PATH`へ分類する。
- TypeScript境界とhosted runnerは固定列挙だけを受け付け、未知suffix、自由文字列、生path、identity、PID、QPCを拒否する。
- 認可、容量actual、候補保存、公開条件は変更しない。

## セキュリティ境界

診断は既存の`BIRTH_MISSING`、System PID 0/4、write、未結合FileObject、既知path判定を通過した場合だけ実行する。分類中もfilesystem identityを読み直し、値そのものは出力しない。固定stage取得だけで代理認可せず、hosted結果を別変更で判断する。

CHG-F005-022反映後のnative pinはProgram SHA-256 `675262137df85a603bca8bf8ba52597a719e6b67ff219f5a2d21237faf4ec8e8`、output binary SHA-256 `cf32d205fd78906d93f68337553c1327aa885599bf48044dbef1c1b203814d08`、75,024,220 bytesとする。

## 検証

- 固定10 stageの優先順位、未知値拒否、最大長127以下を検査する。
- native規則105件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。
- 独立レビューの初回Medium 1件とLow 1件を解消し、最終判定High/Medium/Low 0件をPASSした。hosted productionで固定stageを取得する。

## 承認

認可を変更しない診断追加であり、要求承認ゲートは設けない。固定stage取得と影響試験完了まで`in-review`を維持する。
