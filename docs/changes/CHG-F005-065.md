# CHG-F005-065 current binding proofのRetired契約復元

## 変更理由

T-138 hosted run `31255886029` はstate not bound allへ到達した。T-137以前のproduction `ProofCandidate` は `MatchesGeneration` の既定 `allowRetired:true` を使用していたが、詳細診断化でfalseへ狭まり、既存のRetired generation proofが失敗する退行が入った。認可を拡張せず元の契約を復元する。

## 変更内容

`GenerationMatchResult` のsuccess stateを `Bound or Retired` とし、それ以外を `STATE_NOT_BOUND_OR_RETIRED` に固定する。entry/generation/identity/pathの一致条件、single lookup、outer/inner集約、後段proof再評価0は維持する。旧 `STATE_NOT_BOUND_ALL` は互換allowlistだけに残し、新 `...CURRENT_BINDING_STATE_NOT_BOUND_OR_RETIRED_ALL` を追加して外部集合を75から76へ同期する。認可・state遷移・handoff・候補保存条件はT-137以前から拡張せず、Retired以外の状態を成功させない。

## 影響範囲

CHG-F005-063、CHG-F005-064、T-137、T-138を対象とし、T-139を追加する。

## 試験方針

- Bound/Retired success、Unbound/未知state failureを実ledgerで固定する。
- T-137以前の `MatchesGeneration(..., allowRetired:true)` と新resultの真偽同値を全state・不一致軸で比較する。
- single lookup、後段再参照0、旧code非emit、76 code、非公開、semantic/auth/state/handoff/public/data不変を検査する。
- native全件、固定target、Vitest、typecheck、ESLint、trace_check、再現build2回、独立受け入れ、hosted productionを実施する。

## 承認

既存proof契約の退行修正で要求変更はない。独立設計レビューと影響試験完了までin-reviewを維持する。

## 独立設計レビュー

High 0 / Medium 0 / Low 0でPASSした。T-137以前の既定allowRetired契約の復元、Unbound/未知stateのfail-close、76 code、認可非拡張に残指摘はない。
