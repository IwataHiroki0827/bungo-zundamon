# CHG-F005-031 rename予約前directory writeのlease時間関係固定診断

## 変更理由

Actions run `30525787305`は`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_DIRECTORY_BOUND_LEASE_RENAME_WRITE_REJOIN_BEFORE_RESERVATION`で安全停止した。callback到着は`audio-renamed`後だが、event QPCはrename予約以前であり、lease予約以前かlease予約後かを区別せず認可できない。

## 予定変更

- `BEFORE_RESERVATION`をlease current-path予約QPCとの関係で固定分類する。
- lease予約以前とlease予約後〜rename予約前を分離し、raw QPCを出力しない。
- 認可・容量actual・候補保存・公開条件は変更しない。

## 承認

診断追加のみのため要求承認ゲートは設けない。実装・独立レビュー・hosted影響試験まで`in-review`とする。
