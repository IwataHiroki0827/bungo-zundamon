# CHG-F005-031 rename予約前directory writeのlease時間関係固定診断

## 変更理由

Actions run `30525787305`は`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_DIRECTORY_BOUND_LEASE_RENAME_WRITE_REJOIN_BEFORE_RESERVATION`で安全停止した。callback到着は`audio-renamed`後だが、event QPCはrename予約以前であり、lease予約以前かlease予約後かを区別せず認可できない。

## 予定変更

- `BEFORE_RESERVATION`をlease current-path予約QPCとの関係で固定分類する。
- lease予約以前とlease予約後〜rename予約前を分離し、raw QPCを出力しない。
- 認可・容量actual・候補保存・公開条件は変更しない。

## 変更内容

- rename予約QPC以前のeventだけを、lease `CurrentPathReservedAtQpc`以下の`BEFORE_LEASE_RESERVATION`と、lease予約後からrename予約QPC以下の`AFTER_LEASE_RESERVATION`へ分離した。
- rename予約QPCより後だけ既存のtarget current/identity・Job診断へ進める段階評価を維持した。
- native・TypeScriptの固定allowlistを同時更新し、旧`BEFORE_RESERVATION`と未知suffixをgeneric failureへ閉じた。
- 認可・容量actual・候補保存・公開条件は変更していない。

## セキュリティ境界

CHG-F005-030のtarget・親directory・rename予約存在確認を通過した場合だけlease時間関係を評価する。annotationへraw QPC、path、identityを含めず、両bucketとも診断専用として認可へ接続しない。

native pinはProgram SHA-256 `5e5f9a42d9936f44d728aab52e2721151c76391f7dfc1d8051e6a1a8243f194f`、binary SHA-256 `622186489379d50b29ea07b0ca7b5c868b206e238a492d71c3fc6a72ecabe9c9`、75,032,412 bytesである。
