# CHG-F005-077 追加作者上限を「合計10作者」へ訂正する

## 変更理由

REQUEST.mdの「他に有名な作家を知名度順に10人まで続ける」という要求は、
QA-F005 No.8で「A: 既存3人とは別に追加10人」と解釈され、
`targetAdditionalAuthors=10`（baseline 3 + 追加10 = 最終上限13作者）として
SRS・FD・DD・UT/IT/QT・実装コードへ一貫して反映されていた。

2026-08-20、プロジェクトオーナーへ改めて意図を確認したところ、
正しい意図は「B: 既存を含む合計10人」であることが明示的に判明した。
すなわち `targetAdditionalAuthors=7`（baseline 3 + 追加7 = 最終上限10作者）が
正である。F005（夏目漱石）は変わらず追加1人目だが、残人数は9人→6人、
最終上限は13作者→10作者へ変わる。

## 変更内容

`targetAdditionalAuthors=10`・`finalAuthorLimit=13`という誤った数値定数と、
それに伴う「残9人」「追加1/10」等の自然文記述を、
`targetAdditionalAuthors=7`・`finalAuthorLimit=10`・「残6人」「追加1/7」へ訂正する。
QA-F005 No.8の回答をAからBへ訂正し、訂正履歴を追記する。
