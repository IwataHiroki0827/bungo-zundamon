# CHG-F005-039 retained parent post-reservation late event固定診断

## 変更理由

commit `4dc7d2b44c1fefe80b0816185e560917e547755b`のActions run `31197869896`は、native build、pin、VOICEVOX取得を通過し、T-070 production pipelineの`temporary-written`後に`F005_ETW_WRITE_COMPLETION_DRAIN_LATE_EVENT_AFTER_SEAL`で安全停止した。candidate保存はskipされ、Pages公開は行われていない。

実コードではcompletion drainがactive lease directory認可より先に評価される。完了済みsealはphase終了まで`CompletedRetained`で残り、連続音声は同じ親directoryを共有するため、別active lease予約後のsame-parent eventも旧sealのbroad候補になり得る。ただし現行の公開診断はeventがwrite/setinfoのどちらか、current/parentのどちらか、旧seal/別active leaseの関係、現在lease予約QPCとの関係を示さない。run証跡だけでは「新lease由来event」を証明できず、旧lease由来の遅延parent eventも同じpath/QPC条件を満たし得る。根拠なく旧sealを候補除外すると認可集合を拡張するため、遮蔽変更は行わず固定診断だけを追加する。

## 予定変更

### 1. 2個の複合bucket

既存generic `F005_ETW_WRITE_COMPLETION_DRAIN_LATE_EVENT_AFTER_SEAL`をfallbackとして維持し、exact late tupleが次の全条件を満たす場合だけ2 codeへ細分化する。

- seal stateが`CompletedRetained`である。
- event pathがseal `ParentPath`である。
- `pendingWriteLease`が存在し、seal leaseとは別参照である。
- 現在lease current pathの親directoryがevent pathと一致する。
- event QPCが現在leaseの`CurrentPathReservedAtQpc`より後である。同値以前は該当しない。
- event kindはwriteまたはsetinfoである。

固定codeは次の2個だけとする。

1. `F005_ETW_WRITE_COMPLETION_DRAIN_LATE_RETAINED_PARENT_OTHER_ACTIVE_SAME_PARENT_POST_RESERVATION_WRITE`
2. `F005_ETW_WRITE_COMPLETION_DRAIN_LATE_RETAINED_PARENT_OTHER_ACTIVE_SAME_PARENT_POST_RESERVATION_SETINFO`

各codeはevent kind、parent path kind、`CompletedRetained`、別active lease、same parent、予約QPC後の5軸を含み、長さは100/102文字で既存の許容上限127文字以内に収める。current path、`CompletionRequested`、active leaseなし、同一lease、別parent、予約QPC同値以前、想定外event kindは既存generic LATEを返す。

### 2. 認可・状態非変更

純粋規則は診断codeを選ぶだけで、broad/epoch/exact候補、selected seal、producer tuple、ledger/proof、retained handle、queue、semantic map、capacity、notice、Observationを変更しない。診断後は従来と同じ位置でthrowし、後段active lease directory認可へ流さない。既存21 codeへ上記2 codeだけを追加して23 codeとし、native reply、TypeScript bridge、runner、workflow annotationのexact allowlistを同期する。unknown/extra codeとexact 128文字codeは従来どおりgeneric化する。

optional fieldや追加diagnostic IPCはABI変更が大きいため採用しない。raw path、QPC、FileObject、identity、handle、PIDをannotation、reply、journalへ追加しない。candidate保存、Pages公開、`public/`、`data/`条件は変更しない。

- production共有純粋規則へ、seal state、path kind、active lease有無/同一性、same parent、予約QPC同値/+1、write/setinfoを投入し、全条件一致の2ケースだけ新code、それ以外はgeneric LATEとなることを固定する。
- 2 codeのexact文字列・100/102文字、既存21 code＋2の23 code集合、許容上限127文字、unknown/extra/exact 128文字generic化をnative、bridge、runner、workflow構造試験で確認する。
- 後段active lease認可methodが未到達であり、失敗前後でledger、proof cursor、queue、semantic map、capacity、notice、Observation、seal、leaseが無変更であることを確認する。
- native executable rules、関連Vitest、typecheck、ESLint、trace、再現build 2回、独立受入、`public/`・`data/`差分0を確認する。
- hosted productionを新commitで実行し、run `31197869896`相当が新write/setinfo codeのどちらか、または仮説外としてgeneric LATEのどちらを返すかを証拠化する。認可変更は次の根拠付き変更へ分離する。
