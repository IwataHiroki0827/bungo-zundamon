# CHG-F005-023 System未結合writeその他既知pathの固定bucket

## 変更理由

GitHub Actions run `30518908190`は`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_PROCESS_UNBOUND_FILE_OBJECT_WRITE_KNOWN_PATH_OTHER_KNOWN_PATH`で安全停止した。active lease pathと完了write台帳のいずれにも一致しない既知pathであり、directory metadataとfile writeを区別する必要がある。

## 変更内容

- CHG-F005-022の`OTHER_KNOWN_PATH`だけを、top-level、拡張子、実体種別、active lease結合状態の固定bucketへ細分化する。
- 長さ上限を守る短縮prefix `ETW_PID_NOT_JOB_MEMBER_SYSTEM_UNBOUND_WRITE_OTHER_KNOWN_PATH_`を使用する。
- TypeScript classifierとrunnerは固定列挙に完全一致する値だけを伝播し、未知suffixをgeneric/nullへ閉じる。
- active lease候補、完了write候補、認可、容量actual、候補保存、公開条件は変更しない。

## セキュリティ境界

既存のSystem PID 0/4、write、FileObject未結合、既知path、active lease非一致、完了write非一致を通過した場合だけbucket化する。path文字列やidentity、PID、FileObject、QPC、host固有値は出力しない。

CHG-F005-023反映後のnative pinはProgram SHA-256 `82461e7202102baeff078bafda13010345be526564b86cecb684c7ed48da2944`、output binary SHA-256 `2065aa50e74f60e3bc7d16f18af14c26462ddfd593f39fb491b02c5d8bc289af`、75,024,220 bytesとする。

## 検証

- 最大長、固定bucket、未知suffix拒否、runner exact伝播を検査する。
- native規則105件、対象回帰124件、型、ESLint、同一SHAの再現build 2回、trace、`git diff --check`、公開差分0をPASSした。
- 独立レビューの初回Low 1件を解消し、最終判定High/Medium/Low 0件をPASSした。hosted productionで固定bucketを取得する。

## 承認

認可を変更しない診断追加であり、要求承認ゲートは設けない。固定bucket取得と影響試験完了まで`in-review`を維持する。
