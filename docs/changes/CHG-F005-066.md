# CHG-F005-066 parent not-unboundのledger state固定診断

## 変更理由

T-139 hosted run `31256375723` attempts 2-4は全post-upper parent proofが `IsUnbound(fileObject) == false` で安全停止した。認可を変えず、ledgerの単一entry lookupから観測可能なstate原因を固定する。

## 変更内容

ledgerへread-only `UnboundMatchResult` を追加する。fileObject 0はinvalid、entry missingまたはState Unboundはsuccess、State Boundはbound、State Retiredはretired、その他はother stateとし、単一TryGetValue lookup exact1回で返す。未知resultはSTATE_CHANGEDへ閉じ、raw state・entry値は返さない。

outer LateProofResultが全件parent not-unboundの場合だけinner集約し、単一原因ALLまたはMIXEDへ固定する。別outer cause混在は既存top-level MIXED、invalid/unknown/pair不整合は全後段前STATE_CHANGEDとする。

- `...POST_UPPER_PROOF_PARENT_BOUND_ALL`
- `...POST_UPPER_PROOF_PARENT_RETIRED_ALL`
- `...POST_UPPER_PROOF_PARENT_OTHER_STATE_ALL`
- `...POST_UPPER_PROOF_PARENT_STATE_MIXED`

旧PARENT_NOT_UNBOUND_ALLは互換のみ、新4 code追加で外部集合を76から80へ同期する。proof再評価、ledger再lookup、認可、state、handoff、候補保存条件は変更しない。

## 試験方針

- 実ledgerのmissing/Unbound success、Bound/Retired/unknown failureを固定する。
- 各ALL 1/2/128、全pair/triple/all、反転、invalid/unknown/pair/count不整合を検査する。
- outer/inner境界、lookup exact1、後段再参照0、旧code非emit、80 code、127文字、非公開、semantic/auth/state/handoff/public/data不変を回帰する。
- native全件、固定target、Vitest、typecheck、ESLint、trace、再現build2回、独立受け入れ、hosted productionを実施する。

## 承認

既存ledger stateの診断のみを追加するdesign-level変更で要求承認は不要。独立設計レビューと影響試験までin-reviewを維持する。

## 独立設計レビュー

High 0 / Medium 0 / Low 0でPASSした。現IsUnbound契約の排他的写像、outer/inner境界、80 code、非公開・認可非変更に残指摘はない。
