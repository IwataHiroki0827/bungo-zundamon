## 未実施・残課題（設計・実装判断が必要なため本タスクでは実施していない）

UT-F005-033/034/035/036/037/038/039/042/044/046の10件（およびそれに依存する
IT-F005-010/012/013の3件）は、対応する実装が`src/content/`配下に一切存在しない。
これらはDD-F005.mdに設計は記載されているが、以下のとおり規模の異なる10個の
未着手サブシステムであり、前回解消したFUN-F005-014のような「既存の単純な同型
実装パターンを忠実に踏襲できる1関数」には該当しないため、本タスクの制約（設計判断を
要する新規実装を勝手に進めない）に従い実装しなかった。

- **release/deployパイプライン一式**（FUN-035〜039）: release準備・clean build検証
  （Job収容ETW）・公開記録CAS・rollback・disable recovery。既存のF002/F004向け
  generic batch-productionとは別に、F005固有のhosted deploy adapter・capacity
  recorder統合が必要。
- **static security審査・6環境browser matrix実行**（FUN-033/034）: CSP/secret
  scanner、6ブラウザ環境でのroute/asset網羅検証を行う新規実行系。
- **CAS付き1段階状態遷移**（FUN-042）: 既存の汎用`transitionWorkState`
  （in-memory manifest操作）とは異なり、workspace・exclusive lock・journal・CAS
  を伴うF005専用ラッパーが必要。
- **第三裁定authorization発行・解決**（FUN-044/046）: 既存の`issueF005ReviewAuthorizations`
  /`sealF005ReviewJudgment`/`reconcileF005PrimarySecondary`とは別に、
  一回限りtoken発行・二重mint拒否・dispute結合を伴う新規CAS store型が必要。
