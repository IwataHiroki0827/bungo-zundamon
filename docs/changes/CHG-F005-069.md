# CHG-F005-069 parent bound event FileObject不一致のledger関係固定診断

## 変更理由

CHG-F005-068 hosted run `31623037336` attempt 2は、post-upper proofの全parentがledger Boundであり、phase一致・same parent・予約後を満たしたうえで、late eventのFileObjectがactive leaseのFileObjectと異なるため `...POST_UPPER_PROOF_PARENT_BOUND_EVENT_FO_MISMATCH` で安全停止した。

現在の停止点は「event FOがactive lease FOと違う」ことしか示さず、そのevent FOがledger上どの実体に対応するかが観測できない。認可・handoff・再結合条件を一切変えず、event FOのledger関係だけを固定分類して次の原因分離へ進む。

なお同一commit系列のrun `31623929980` attempts 1-3は `EVENT_TUPLE_LOOKUP_EXACT_MISSING` と `STATE_CHANGED` の既知経路であり、本軸への到達はhosted schedulingに依存する。

## 変更内容

`ParentBoundActiveLeaseFailureCode` の評価順・既存分岐を変更しない。`eventFileObject != activeLeaseFileObject` で従来 `EVENT_FO_MISMATCH` を返していた分岐だけを、event-global scalarによる固定分類へ差し替える。

追加引数はledgerへのread-only single lookupで得た `EventFileObjectMatchResult?` 1値とする。ledgerへ `MatchEventFileObject(fileObject, activeLeasePath)` を追加し、単一 `TryGetValue` exact 1回でstateとpath一致を同時に判定して `Invalid` / `EntryMissingOrUnbound` / `BoundSamePath` / `BoundOtherPath` / `RetiredSamePath` / `RetiredOtherPath` / `OtherState` を返す。raw path・raw FileObject・entry値・件数は返さない。lookupはCHG-F005-067の判定ブロック内でのみ、event-global exact 1回評価する。

分類は次の固定7 codeとし、共通prefixは `...POST_UPPER_PROOF_PARENT_BOUND_EVENT_FO_` とする。

- `ENTRY_MISSING_OR_UNBOUND` — ledger entryなし、またはState Unbound
- `BOUND_SAME_PATH` — State Bound、pathがactive lease pathと一致
- `BOUND_OTHER_PATH` — State Bound、pathが不一致
- `RETIRED_SAME_PATH` — State Retired、pathが一致
- `RETIRED_OTHER_PATH` — State Retired、pathが不一致
- `OTHER_STATE` — 上記以外の既知state
- `LOOKUP_INVALID` — lookupがInvalidを返した場合

引数がnull（ledger不在）またはenum未定義値の場合は後段前に `STATE_CHANGED` へ閉じる。

旧 `EVENT_FO_MISMATCH` は互換・他経路のために残し、新7 code追加で外部code集合を90から97へ同期する。候補生成、handoff、OtherBound admission/apply、semantic map、auth fingerprint、active lease、state、容量actual、候補保存条件、公開条件はいずれも変更しない。

## 試験方針

- 7 codeそれぞれの単独到達と、既存validation（count/event/eventFO/context/tuple/phase/parent/reservation order）が優先されることを固定する。
- `EntryMissingOrUnbound` がpath値に依存しないことを固定する。
- null・enum未定義値・`Invalid` の扱いを固定し、後段（LEDGER_MISSING、write/setinfo exact）への到達0を確認する。
- ledger lookupがevent-global exact 1回であることを回帰する。
- 97 code同期、raw値非公開、127文字上限、semantic/auth fingerprint不変、`public/`・`data/` 差分0を回帰する。
- native全件、固定target suite（52/57/43/74）、Vitest、typecheck、ESLint、trace_check、同一SHA再現build 2回、独立受入、hosted影響試験を実施する。

## 承認

非破壊診断のみのdesign-level変更。認可条件・公開条件を変更しないため、独立レビューと影響試験までin-reviewとする。
