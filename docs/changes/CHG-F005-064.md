# CHG-F005-064 current binding mismatchのledger軸固定診断

## 変更理由

CHG-F005-063 production run `31254910006` は、全post-upper sealがcurrent FileObject一致後の `MatchesGeneration(..., allowRetired:false) == false` で安全停止した。ledgerが保持する単一entryを一度だけ観測し、内部値を公開せず不一致軸を固定する。

## 変更内容

`WriteCompletionBindingLedger` にread-onlyの `GenerationMatchResult` を追加し、同一entry lookup exact 1回からentry missing、generation mismatch、identity mismatch、path mismatch、state not bound、success、invalidの排他的結果を返す。invalidはfileObject 0、generation 0以下、identity/path nullまたは空とする。局所優先順はinvalid validation、entry missing、generation、identity、path、state、successとする。identity/pathは既存 `MatchesGeneration` と同じordinal完全一致、state not boundはproductionの `allowRetired:false` と同じ `State != Bound` を意味する。未知resultはSTATE_CHANGEDへfail-closeする。raw generation、identity、path、stateは返さない。

CHG-F005-063のcurrent binding分岐でこの結果をexact 1回取得する。先にouter `LateProofResult` を全sealで集約し、invalidは常にSTATE_CHANGED、successがあれば既存late経路、ledger unavailable/current FileObject mismatch/parent not unbound/current bindingが混在すれば既存top-level `POST_UPPER_PROOF_MIXED` とする。全sealのouter結果がcurrent bindingの場合だけinner集約へ進み、単一inner原因なら対応ALL、複数inner原因なら新 `CURRENT_BINDING_MIXED` へ固定する。inner結果をouter causeへ昇格・混同しない。

- `...POST_UPPER_PROOF_CURRENT_BINDING_ENTRY_MISSING_ALL`
- `...POST_UPPER_PROOF_CURRENT_BINDING_GENERATION_MISMATCH_ALL`
- `...POST_UPPER_PROOF_CURRENT_BINDING_IDENTITY_MISMATCH_ALL`
- `...POST_UPPER_PROOF_CURRENT_BINDING_PATH_MISMATCH_ALL`
- `...POST_UPPER_PROOF_CURRENT_BINDING_STATE_NOT_BOUND_ALL`
- `...POST_UPPER_PROOF_CURRENT_BINDING_MIXED`

旧 `CURRENT_BINDING_MISMATCH_ALL` は外部互換allowlistへ残すが新sourceからemitしない。invalidは他cause/success混在でも全後段前STATE_CHANGEDを最優先する。ledger再lookup、proof再評価、wait、再lock、認可、state、handoff、候補保存条件は変更しない。互換旧codeを保持して新6 codeを追加するためcompletion-drain集合を69から75へ同期する。

## 影響範囲

`REQ-F005-012`、`REQ-F005-013`、`DES-F005-006`、`DES-F005-012`、`FUN-F005-017`、`FUN-F005-047`、`UT-F005-017`、`UT-F005-047`、`IT-F005-005`、`QT-F005-008`、`QT-F005-009`、`T-070`、`T-137`を対象とし、`T-138`を追加する。

## 試験方針

- 各単一原因ALL 1/2/128、全pair/triple/allのMIXEDと順序反転を実ledgerで固定する。
- fileObject 0、generation 0以下、identity/path null・空のinvalid各軸、invalid+success/別cause、129件、overflow、unknown resultを全後段前STATE_CHANGEDへ閉じる。
- entry missing+任意期待値、generation+identity/path/state、identity+path/state、path+stateの複合不一致で局所優先順を固定する。outer別cause混在はtop-level MIXED、全outer current bindingの場合だけinner ALL/MIXEDとなることを固定する。
- lookup exact1回、原因別後段ledger参照0回、旧code非emit、75 code共有、127文字以内、情報非公開を検査する。
- `MatchesGeneration`既存利用者、semantic fingerprint、認可・state・handoff・public/data不変を回帰する。
- native全件、固定target、関連Vitest、typecheck、ESLint、trace_check、再現build2回、独立受け入れ、hosted productionを実施する。

## 承認

既存ledger snapshotの不一致軸を認可せず固定するdesign-level変更で、要求承認ゲートは設けない。独立設計レビューとlocal/hosted影響試験完了まで `in-review` を維持する。

## 独立設計レビュー

初回レビューのMedium 4件を受け、互換旧codeを含む75 codeへ修正し、outer/inner二段集約、invalid・文字列・state契約、複合不一致試験を明文化した。最終レビューはHigh 0 / Medium 0 / Low 0でPASSし、単一lookup、排他的partition、非公開、認可・state・handoff非変更に残指摘はない。
