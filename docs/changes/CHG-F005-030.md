# CHG-F005-030 bound lease rename中directory writeの固定診断

## 変更理由

Actions run `30524741788`は`audio-renamed`後、`F005_ETW_PID_NOT_JOB_MEMBER_SYSTEM_DIRECTORY_BOUND_LEASE_WRITE_REJOIN_LEASE_CURRENT_MISSING`で安全停止した。active leaseの旧temporary pathがrename後に消えているため、予約済みrename先との関係を確認する必要がある。

## 変更内容

- `LEASE_CURRENT_MISSING`時だけ、pending rename path、同一親directory、rename予約QPC、eventの予約後到着、target current/identity、Job escapeを固定8 stageへ分類する。
- 観測QPCをSystem write診断へ渡し、予約以前を`BEFORE_RESERVATION`で拒否する。
- `CANDIDATE`でも認可せず、容量actual・候補保存・公開条件を変更しない。

## セキュリティ境界

CHG-F005-029のdirectory・lease snapshot・binding完全一致を通過した場合だけrename診断へ進む。生path・identity・QPC等を出さず、未知suffixはgeneric/nullへ閉じる。

native pinはProgram SHA-256 `fc6fc09f0d8e9b231c2d94ebea21e90fcb1704392a70451fced2ce4b53d1e3e4`、binary SHA-256 `c4d51941b6bbb2a383426780be5f84cc85e8588d04a419fa904e7c05f22ab1df`、75,032,412 bytesである。

## 検証

- 固定8 stage、段階評価、QPC境界、target identity、Job評価、未知suffix、runner伝播、認可不変を検査する。
- native規則173件、対象124件、型、ESLint、同一SHA再現build 2回をPASSした。
- 初回レビューLow 2件をhelper唯一経路・runner未知suffix拒否の明示試験で解消し、trace・差分・公開差分0・最終独立レビューHigh/Medium/Low 0をPASSした。
- commit固定のhosted productionを再試験する。
