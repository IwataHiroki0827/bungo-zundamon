# CHG-F005-073 封緘済み選定snapshotをcollect-sourceで再利用する

## 変更理由

`scripts/f005-collect-source.ts` は `selection` フェーズで、対象作品によらず
毎回 `collectF005SourceSnapshot` を呼んで青空文庫から書誌・著者ページ・
規約・全作品の原典を再取得している。取得したbytesは
`writeF005SourceArtifactOnce` / `writeJsonArtifactOnce` で封緘保存される。

しかしREQ-F005-005が求める選定時snapshotは**バッチ単位で一度**取るものであり、
F005では 2026-07-29 に3作品（000799 / 001076 / 001104）分をまとめて封緘済みである。

```
data/batches/F005/source-snapshots/selection/works/000799/{card.html,source.raw}
data/batches/F005/source-snapshots/selection/works/001076/{card.html,source.raw}
data/batches/F005/source-snapshots/selection/works/001104/{card.html,source.raw}
```

この状態で2作品目の候補抽出のために `collect-source selection 001076` を実行すると、
再取得した書誌ZIPが封緘済みのものと一致せず停止する。

```
Error: 既存binary artifactが不一致です:
  data/batches/F005/source-snapshots/selection/bibliography.zip
```

青空文庫の `list_person_all_extended_utf8.zip` は**新規作品の追加により日々更新される**
全作品リストであり、選定時と同一bytesが再取得できるのは事実上初回のみである。
つまり現状の実装は**バッチの1作品目でしか成功しない**。実際にF005の作品追加は
この地点で停止していた。

対象3作品の権利属性（作品著作権フラグ・人物著作権フラグ・文字遣い種別・公開日・
最終更新日）は 2026-08-14 時点の最新書誌と照合して全項目一致であり、
差分は無関係な作品の追加分（2,092,213 → 2,092,586 バイト）のみであることを確認した。
権利判断に影響する変更ではない。

## 変更内容

`selection` フェーズで選定snapshotが既に存在する場合、再取得せず
`rehydrateF005SelectionSnapshot` で封緘済みartifactから復元する。

```ts
const sealedSelection = phaseArg === 'selection' && await exists(selectionSnapshotPath)
  ? await rehydrateF005SelectionSnapshot(workspace, context)
  : undefined;
const snapshot = sealedSelection ?? await collectF005SourceSnapshot(...);
```

`rehydrateF005SelectionSnapshot` は復元時に各artifactのSHA-256を照合するため、
封緘済みbytesの同一性検証は維持される。以降の書き込み経路は変更しない。
復元したbytesは封緘済みbytesと同一であるため、`*Once` 系の書き込みは
同一内容の再書き込みとして通過する。

## 失う性質と、それを許容する根拠

2作品目以降の候補抽出時に、規約snapshotの再取得が走らなくなる。
ただし次の理由から許容する。

- 規約の再確認は `predeploy` フェーズが独立snapshotとして実施しており、
  REQ-F005-005 が求める二重確認はそちらで担保される。
- 選定時snapshotは「**選定した時点**の状態」の記録であり、作品ごとに
  時点が変わる方が記録としてむしろ不正確である。
- 同一バッチ内の3作品は同一時点で選定されている（`observedAt: 2026-07-29T04:18:45.001Z`）。

## 影響範囲

- `scripts/f005-collect-source.ts` — `selection` フェーズのsnapshot取得元
- 既存の封緘済みartifact — 変更なし
- `content/batches/F005/source-snapshots/selection.json` — 変更なし
