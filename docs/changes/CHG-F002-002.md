# CHG-F002-002: F002の手動確認必須条件を廃止

| 項目 | 内容 |

| 発生日 | 2026-07-26 |

| 承認 | 本会話での直接指示を要求変更の明示承認として記録 |
| 状態 | done |

## 変更理由

F002のIT・QT・リリース判定には、物理iOS Safari、手動スクリーンリーダー、画面目視、実音声聴取、公式URL目視など、人の追加入力を要求する条件が残っていた。これらがT-029の進行を止め、ProjectFactory画面での反復入力を必要としていた。

## 変更内容

- F002の適格性・リリース判定は、自動試験と機械検証可能な証跡だけで完結させる。
- 手動操作、物理実機、目視、実音声聴取、スクリーンリーダー実操作は、F002の必須証跡から外す。
- 未実施の手動確認をPASSへ読み替えない。対象外とした理由を明記し、自動試験の実測結果だけをPASS根拠にする。
- 既に確定済みの編集レビュー、権利判断、作者画像判断は、候補・原典・規約・画像実体へ結合された既存artifactとして扱い、schema、必須項目、hash chain、全件性を自動検証する。新たな人手判断は要求しない。
- ブラウザ・アクセシビリティは、CIで再現可能なPlaywright Chromium/Firefox/WebKit/Android相当、3 viewport、keyboard、semantic/ARIA、reduced motionの自動試験で判定する。
- 音声はWAV構造、PCM metadata、SHA-256、bytes、duration、設定hash、AudioPort状態遷移を自動検証し、聴取を要求しない。
- ProjectFactoryの要求・設計・テスト仕様・リリースという4承認ゲートは維持する。今回の要求変更承認は本会話の直接指示で完了とし、同一内容を再入力させない。
