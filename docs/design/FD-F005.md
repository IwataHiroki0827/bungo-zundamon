# 機能設計書 F005（夏目漱石3作品追加）

## 1. 設計方針

F005は公開済みv0.4.0を固定baselineとし、4人目の作者として夏目漱石と「夢十夜」「倫敦塔」「趣味の遺伝」を順次追加する。F004までに確立した承認binding、原典固定、独立二重レビュー、差分音声、作品単位atomic受入、Catalog統合、お気に入り、段階公開を共通基盤として再利用する。

F005固有の変更は次の境界へ閉じ込める。

- 公式カードに校正者欄がない場合を`proofreader: null`で表現する書誌schemaの後方互換拡張
- 「趣味の遺伝」raw XHTMLの`notation_notes`にある連続exact 2件の`&nbsp;`だけをparse前に変換する決定的正規化
- 夏目漱石の新規author identity、独自作者画像、3作品、公式表現注意のデータ駆動追加
- 公開済み3作者とは別に追加10作者まで進める順位計画の再現可能な管理

作者名、作品名、作品ID、注意文によるapplication code分岐は追加しない。固有値はApproved definition、source evidence、Catalog fragmentへ置き、共通validatorとprojectorへ渡す。永続artifactのpathはworkspace相対POSIX形式で保持し、filesystem境界でのみ検証済み絶対pathへ解決する。

信頼境界は`VerifiedApprovalBindingPolicy`と`ApprovedBatchContext`で表す。module-private loaderだけが内部定数のF005 approval snapshot完全SHAとmodule-private canonical path/hash表からpolicyをmintし、外部descriptorは使わない。後続関数はcontextまたはcontext由来brandだけを受け取る。永続pathは危険形式を拒否し、trusted root内のregular fileをhandle identity付きで処理する。
