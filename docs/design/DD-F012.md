# 関数設計書 F012（聴く体験の拡充、v1.1.0）

## 1. 連続再生 [DES-F012-001]

### FUN-F012-001: AudioController.playSequence(key, items) / stopSequence() / sequence [DES-F012-001]

`src/ui/audio-controller.ts`。`playSequence(key: string, items: readonly CatalogDialogue[]): Promise<PlayerState>`は、keyが空・未知台詞を含む場合は何もしない。
開始後は内部`#playSequenceItem`で既存`play()`を呼ぶ（同一台詞が続く場合は停止状態から読み直す）。`#handleEnded`は現在の連続再生位置と一致する場合だけ次へ進む。
`stopSequence(): PlayerState`は解除して停止する。`get sequence(): {key,index,total} | null`は表示用の進行状況を返す。

### FUN-F012-002: renderSequenceControl(controller, workId, title, items) -> HTMLButtonElement [DES-F012-001]

`src/ui/render-f012.ts`。作品パネルの`.work-actions`へ置くbutton。controller購読で`aria-pressed`・`aria-label`（「連続再生：作品名」/「連続再生を止める：作品名」）・表示を更新する。
`playSequence`を持たないcontrollerでは無効化する。

## 2. お気に入りの移行 [DES-F012-002]

### FUN-F012-003: buildFavoriteExport(store) -> string / parseFavoriteImport(raw, catalog) -> FavoriteImportResult [DES-F012-002]

`src/ui/favorites-transfer.ts`。書き出しは`{format, version: 1, dialogueIds}`の整形JSON。取り込みは先頭BOMを許容し、
サイズ262,144 code unit超→`too-large`、JSON不正→`malformed`、plain object以外・key集合が`dialogueIds,format,version`以外・format/version/型/件数/ID文字種違反→`schema-invalid`、
Catalogに1件もない→`empty`。成功時は重複除去・Catalog順のIDと除外件数を返す。

### FUN-F012-004: buildFavoriteShareUrl(baseUrl, ids) / parseFavoriteShareParam(search, catalog) / withoutFavoriteShareParam(href) [DES-F012-002]

共有URLは`fav=v1:<id>,...`・hash`#/favorites`、1〜100件以外は`null`。解析はparam無し→`null`、複数指定・prefix違い・件数/文字種違反→`schema-invalid`。
`withoutFavoriteShareParam`は`fav`だけを除いたURLを返す（`mountBungoZundamon`が起動時に`history.replaceState`で使用）。

### FUN-F012-005: FavoriteController.merge(ids) -> FavoriteMergeResult [DES-F012-002]

`src/ui/favorites.ts`。保存直前に`reload()`し、Catalogに存在し未登録のIDだけを上限（5000件）内で追加して既存`save`で1回保存する。
`{snapshot, added, alreadySaved, ignored}`を返し、dispose後は保存しない。

### FUN-F012-006: renderFavoriteTransfer(catalog, favoriteController, baseUrl) / renderShareOffer(offer, favoriteController, onResolved) [DES-F012-002]

お気に入り画面の「書き出し・取り込み」section（ファイル書き出し・ファイル取り込み・共有リンク作成、結果はaria-live）と、共有リンクで開いた時の確認section。
確認sectionは「お気に入りに追加する」を押した時だけ`merge`する。

## 3. 検索 [DES-F012-003]

### FUN-F012-007: normalizeSearchText(value) / searchDialogues(catalog, query, authorId?, limit?) [DES-F012-003]

`src/ui/search.ts`。正規化はNFKC→小文字→カタカナをひらがなへ→空白・括弧・句読点類を除去。検索はCatalog順に作品名・作者名・原著者名・台詞を部分一致し、
`{total, hits(先頭limit件)}`を返す。query・作者が共に空なら0件。

### FUN-F012-008: renderDialogueSearch(catalog, controller, favoriteController) [DES-F012-003]

トップの「台詞をさがす」section（`role=search`のcontrols、再生設定、aria-live status、結果`ol`）。入力・作者変更のたびに結果を作り直し、旧カードの購読を解除する。

## 4. 再生設定 [DES-F012-004]

### FUN-F012-009: AudioController.setPlaybackRate(rate) / setVolume(volume) / playbackSettings [DES-F012-004]

速度は`PLAYBACK_RATES = [0.75, 1, 1.25, 1.5]`だけを受け付け、音量は有限値を0〜1へclampし小数2桁に丸める。dispose後は変更しない。

### FUN-F012-010: renderPlaybackSettings(controller) -> HTMLElement [DES-F012-004]

`role=group`・`aria-label=再生設定`。速度select、音量range（`aria-valuetext`と`output`を同期）。設定APIを持たないcontrollerでは無効化する。

## 5. 今日の一台詞 [DES-F012-005]

### FUN-F012-011: tokyoDateKey(date) / selectDailyDialogue(catalog, dateKey) [DES-F012-005]

`src/ui/daily.ts`。UTC+9の暦日`YYYY-MM-DD`。選択は`FNV-1a32("bungo-zundamon:daily:" + dateKey) mod 全台詞数`。台詞0件は`null`、不正日付は例外。

### FUN-F012-012: renderDailyDialogue(catalog, controller, favoriteController, now) [DES-F012-005]

トップの「今日の一台詞」section（日付・作者・作品、既存`renderDialogueCard`、作者ページlink）。`renderAuthorIndex`の第3引数（controller等）がある場合だけ描画する。

## 6. オフライン [DES-F012-006]

### FUN-F012-013: service worker（src/sw/service-worker.js） [DES-F012-006]

install/activate/fetch handler。取得方針はFD-F012 DES-F012-006のとおり。Range解析は`bytes=a-b`・`bytes=a-`・`bytes=-n`を受け付け、範囲外は416。

### FUN-F012-014: renderServiceWorker(source, version, precache) / requiredContentFiles(publicDir) / buildWebManifest(icon) / serviceWorkerPlugin({projectRoot}) [DES-F012-006]

`scripts/service-worker-build.mjs`。版数は16〜64桁hex、precacheは`..`・scheme・空白を含まない相対pathだけ（重複除去・整列）。placeholderが無いtemplateは拒否する。

### FUN-F012-015: registerAppServiceWorker(baseUrl, container?, secure?) -> Promise<boolean> [DES-F012-006]

`src/ui/offline.ts`。secure contextかつservice worker対応時だけ`<base>sw.js`を`{scope: base.pathname, updateViaCache: 'none'}`で登録し、失敗は`false`で吸収する。

### FUN-F012-016: planOfflineAudio(ids, catalog, budget?) / OfflineAudioManager [DES-F012-006]

計画はCatalog順・同一path重複除去・上限超過件数を返す。`OfflineAudioManager`は`status/enable/sync/disable/subscribe`を直列化して実行し、
markerがある場合だけ同期する。取得は`credentials: same-origin`・`redirect: error`・`cache: no-store`、bytes/SHA-256不一致は保存しない。

### FUN-F012-017: renderOfflineAudioPanel(manager, favoriteController) [DES-F012-006]

お気に入り画面の「オフライン再生」section。未対応環境ではbuttonを無効化し理由を表示、保存件数・容量・上限超過/空き不足/取得失敗件数をaria-liveで表示する。

## 7. 作品データ [DES-F012-007]

### FUN-F012-018: renderWorkBibliography(work, author, authorId) -> HTMLElement [DES-F012-007]

`dl`（作者・作品・底本・収録・原典確認日）と「本文を青空文庫で読む」link（`sourceLinkFor`→`aozoraLinkV2`/`aozoraLink`）。canonical範囲外のURLは例外（route描画は既存のfail-closed表示へ）。
