# 関数設計書 F008（江戸川乱歩3作品追加）

## 0. 再利用方針

F008は「新規作者1人・3作品追加」という構造がF006・F007と同型であり、F005が導入したETW常時監視・native guard機構は使わない。CHG-F005-072以降に確立した「phase前後の実測差分による事後検証」と、F001〜F007実績の汎用release経路は、値がfeatureに依存しない汎用実装であるため直接再利用する。

以降の各`FUN-F008-*`は、DESごとの追跡用論理IDである。多くは実装として新規コードを書かず、既存関数をそのまま呼び出す（本文に既存関数名を明記する）。値（authorId・workId・release commit・catalog SHA・既存作者画像枚数・注記対象2作品等）がfeatureごとに異なるために既存モジュールを直接呼べないもの（baseline pin・author/work registry・source/entity抽出・薄い受入ラッパー・catalog統合・route導出・artwork provenance、計8件）だけを新規コードとして定義する。実装フェーズでは、再利用する既存関数のJSDocへ`@des DES-F008-xxx @fun FUN-F008-xxx`を追記する。
