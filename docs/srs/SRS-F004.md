# 要求仕様書 F004（宮沢賢治追加3作品・お気に入り）

## 1. 目的

公開済みv0.3.0を不変に保ち、既存作者の宮沢賢治へ3作品と対応音声を追加する。同一作者への継続追加をデータ駆動で実証し、作者・route・画像の重複を防ぐ。あわせて、気に入った台詞を端末内へ保存し、作者をまたいで見返せるお気に入り機能を提供する。

## 2. 対象範囲

- 宮沢賢治（人物ID`000081`、既存表示名`みやざわずんじ`）
- `オツベルと象`（`000466`）
- `雪渡り`（`045679`）
- `カイロ団長`（`001918`）
- 既存作者routeへの作品・台詞・同一origin WAV・出典追記
- 全台詞のお気に入り切替、端末内永続化、お気に入り専用route

F004では新作者画像、`『』`単独抽出、長大音声の分割再生、作品全文朗読、収益化変更、アカウント、クラウド同期、共有、利用者追跡を行わない。

## 4. 運用制約

- 手動・実機・目視・聴取・手動スクリーンリーダーは必須PASS証跡に含めない。
- 正式候補数、音声件数、容量は原典固定・review完了後の実測を正とする。
- ProjectFactoryの4承認ゲートを記録し、安全な既定は本会話の包括承認で処理する。
- お気に入りは個人情報を収集せず、ブラウザのサイトデータ削除時に消える端末内機能とする。
