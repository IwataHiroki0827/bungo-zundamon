# 要求仕様書 F003（太宰治コンテンツ追加）

## 1. 目的

公開済みF001/F002を不変に保ったまま、3人目の作者として太宰治の代表3作品を追加する。F002で整備した継続バッチを再利用し、権利確認、全候補レビュー、VOICEVOX差分生成、容量、セキュリティ、公開後スモークを自動証跡で完結する。

## 2. 対象範囲

- 太宰治（人物ID `000035`、表示名`だざいおさむ`）
- `女生徒`（`000275`）
- `走れメロス`（`001567`）
- `グッド・バイ`（`000258`、未完）
- 作者画像、出典、クレジット、CatalogV2、同一origin WAV

F003では長大音声の分割再生、`『』`単独抽出、作品全文朗読、収益化変更を行わない。宮沢賢治「雪渡り」はF004候補に保持する。
