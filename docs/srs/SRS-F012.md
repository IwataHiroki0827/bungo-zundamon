# 要求仕様書 F012（聴く体験の拡充、v1.1.0）

## 1. 目的

公開済みv1.0.0（10作者・33作品・1314台詞・1296音声）のコンテンツ・音声・書誌を一切変更せず、
既存の公開データだけを使って「探す・続けて聴く・持ち運ぶ・通信なしで聴く」体験を追加する。
オーナー指示（2026-10-04、F002〜F011レビュー後の機能提案7件の全件実装）を本書の承認根拠とする（QA-F012.md）。

## 2. 対象範囲

- 作品単位の連続再生、再生速度・音量（session限り）
- トップ画面内の台詞検索・作者絞り込み（新しいrouteを追加しない）
- 日本時間の日付で決まる「今日の一台詞」
- お気に入りの書き出し・取り込み（JSONファイル）と共有リンク
- service workerによるapp shellのオフライン化と、利用者が有効化した場合だけのお気に入り音声保存
- 既存書誌メタデータだけで構成する「作品データ」カードと、青空文庫の図書カード・本文への外部link

F012では、新しい文学解説文の作成、作者・作品・台詞・音声の追加や変更、外部送信・アカウント・アクセス解析、
新しいhash route、端末保存領域の新しいkeyを行わない。

## 3. 要求一覧

| ID | 要求 | 優先度 | 受入基準 |
|---|---|---:|---|
| REQ-F012-001 | 作品内の台詞を順に連続再生できる | 高 | 作品パネルの明示操作でだけ開始し、音声終了で次の台詞へ進み、最後で終了を通知する。一時停止・再開では継続し、停止・別台詞の再生・route切替・音声エラーで解除する。同時再生は常に1件、自動再生（明示操作なしの開始）は0件 |
| REQ-F012-002 | お気に入りを書き出し・取り込み・共有できる | 高 | 書き出しは`{format:"bungo-zundamon-favorites",version:1,dialogueIds}`のJSON。取り込みはexact key・型・件数（5000件）・ID文字種・サイズ（262,144 code unit）を検証し、Catalogにない IDは件数だけ報告して除外する。共有リンクは`?fav=v1:<id>,...#/favorites`で最大100件、開いた時は確認後にだけ取り込み、URLから共有queryを除く。端末保存の読み書きは既存お気に入りmoduleだけが行う |
| REQ-F012-003 | 台詞を検索・絞り込みできる | 中 | トップ画面内でキーワード（台詞・作品名・作者名、NFKC・かな種別・括弧差を吸収）と作者で絞り込み、件数をaria-liveで通知し先頭30件を再生・お気に入り可能なカードで表示する。新しいrouteを追加しない |
| REQ-F012-004 | 再生速度と音量を変更できる | 中 | 速度0.75/1/1.25/1.5倍、音量0〜100%を選べ、音声の読込み直後も設定を維持する。設定は画面を開いている間だけ保持し、端末の保存領域へ書き込まない |
| REQ-F012-005 | 今日の一台詞を表示する | 低 | トップに日本時間の暦日から決定的に選んだ1台詞（`FNV-1a32("bungo-zundamon:daily:"+YYYY-MM-DD) mod 全台詞数`）を表示し、再生・お気に入り・作者ページ移動ができる。表示だけでは音声を取得しない |
| REQ-F012-006 | 通信なしでも利用できる | 中 | 同一originの`sw.js`がapp shellと起動必須dataを版付きcacheへ保存し、通信できない時もトップ・作者ページを表示できる。お気に入り音声は利用者が明示的に有効化した場合だけ、50,000,000 bytes以内かつ端末空き容量（余白10,000,000 bytes）以内で、公開Catalogのbytes・SHA-256一致を確認して保存する。Range要求へ206で応答し、お気に入り解除で削除、無効化で全削除する。版更新時は古いapp shell cacheを削除し、画面遷移・公開dataはnetwork優先とする |
| REQ-F012-007 | 作品の書誌データと原典への導線を表示する | 中 | 作品パネルに既存Catalogの作者・作品・底本・収録台詞数・原典確認日を表示し、青空文庫の図書カードと本文ページを`target=_blank`・`rel="noopener noreferrer"`で開く。linkは作者別canonical範囲（`https://www.aozora.gr.jp/cards/<authorId>/`）だけを許可し、新しい解説文は作らない |
| REQ-F012-008 | 既存契約とセキュリティを維持する | 高 | 既存10作者・33作品・台詞・音声・書誌のbyte不変、公開route exact 13件、初期全閉、お気に入りstorage契約（専用key 1件）、外部request 0、Cookie/form 0を維持する。CSPは`worker-src 'none'`を`worker-src 'self'`へ変更する以外を変えず、静的security検査（release-checks・F002 security）へ`worker-src 'self'`を必須directiveとして追加する。既存Playwright環境と単体・結合試験を回帰させない |

## 4. 運用制約

- 手動・目視・聴取を必須PASS証跡に含めない。
- 公開手順は既存の汎用release経路（`PAGES_DEPLOY_ENABLED`/`PAGES_DEPLOY_COMMIT`ゲート）を使う。F012はコンテンツbatchを持たないため`mark-published.ts`の対象batchはない。
- service worker受入のブラウザ試験はChromium系project（Chromium・Android相当・Chrome stable・Edge stable）で行い、Firefox/WebKitは設計skipとして単体・結合試験で補う（QA-F012.md No.6）。
