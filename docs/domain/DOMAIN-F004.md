# ドメイン調査 F004（宮沢賢治追加3作品）

## 1. Tier判定

調査Tierは**大**とする。外部公開サイトへ文学作品本文を変換した合成音声を追加するため、著作権、青空文庫の利用条件、VOICEVOX・ずんだもん規約、公開容量、文学表現の編集判断が関係する。F002/F003の調査と公開実績を再利用し、青空文庫の公式拡充CSV・図書カード・XHTMLを再確認した。

## 2. 結論

F004は公開済みの宮沢賢治へ、次の新字新仮名3作品を追加する。

| 処理順 | 作品 | 作品ID | 公式XHTMLの`「」`概算 | 主な注意 |
|---:|---|---:|---:|---|
| 1 | オツベルと象 | `000466` | 49 | 搾取・拘束・救出を扱う。語りと発話を区別する |
| 2 | 雪渡り | `045679` | 66 | `『』`6件は現行抽出の対象外。歌・引用・発話を区別する |
| 3 | カイロ団長 | `001918` | 103 | 集団発話、命令、契約文言を文脈付きで判定する |

表の概算はXHTML全体に現れる括弧数であり、本文抽出結果とは区別する。既存抽出器による選定用計測は、オツベルと象46候補・最大242字、雪渡り64候補・最大278字、カイロ団長102候補・最大290字で、500 code point超過0件だった。全候補音声化の安全側予測は合計69,889,648 bytes（66.65 MiB）である。これらも選定用計測であり、正式値は原典byte列、charset、本文selector、SHA-256を固定した後に再確定する。

## 4. 権利・書誌

- 公式拡充CSVで3作品は人物ID`000081`、役割`著者`、人物・作品著作権フラグ`なし`、新字新仮名、公式XHTMLありである。
- 選定時だけでなく公開直前にも同じ条件を再確認し、版・URL・hashの差分時は停止する。
- 作品名、著者、底本、入力者、校正者、取得日、原典hash、加工履歴を保持する。
- 青空文庫の書誌データ利用条件と、個々の本文の権利状態を混同しない。

## 5. 編集・音声・容量

- 本文領域内にある全角`「...」`のうち、入れ子では最外側の括弧だけを候補とし、`『...』`単独、本文領域外、壊れた括弧を公開候補へ入れない。
- 全候補を独立二重判定し、不一致は第三裁定まで`pending`として音声生成を止める。
- 題材だけを理由に実発話を除外しない。表示文と読み上げ文を分離し、固有語・擬音・方言の読み補正履歴を残す。
- 正規化後500 Unicode code point、推定120,000 ms、予測WAV 5,760,044 bytesの単一候補上限を維持する。
- F003公開物は164,314,350 bytesであり、Pages警告524,288,000 bytesまで約359.9 MBある。1バッチの新規WAV 100 MiB以下、Pages 500/750 MiB、repository 750 MB/1 GB、単一object 100 MiBの既存ゲートを維持する。
- 同一作者のため既存作者画像を再利用し、新しい画像を重複生成しない。
- 独立反証評価の初回Low（概算と抽出結果の区別）と再確認Medium（本文領域内・最外側の明記）を反映し、最終High 0 / Medium 0 / Low 0でPASSした。

## 6. 必須要求候補

1. v0.3.0の3作者・9作品・472台詞・463音声を固定baselineとして不変照合する。
2. 同じauthor identityへ3作品だけを追記し、作者カード・route・画像を重複させない。
3. 公式原典、権利、全候補レビュー、読み補正、容量、音声、作品単位受入をF003と同じhash chainで実施する。
4. 全作者routeの作品はページ遷移時を含め初期全閉を維持する。
5. 手動・目視・聴取を必須証跡にせず、自動試験と機械検証可能なartifactで完結する。
