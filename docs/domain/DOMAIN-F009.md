- **外字（gaiji）の新規発見**: 瓶詰地獄・死後の恋のXHTML本文には、JIS X 0208外の文字を表す`<img class="gaiji">`要素（例: 瓶詰地獄「竹かんむり／孤」「登／几」「てへん＋劣」「口＋耳」の4件、死後の恋「てへん＋劣」「月＋咢」の2件）が本文中に存在することを実測で確認した。F005〜F008の採用9作品では`gaiji_list`問題は一切検出されていなかったため、これはF009固有の新規発見である。ただし実測の結果、いずれの外字も抽出済みかぎ括弧候補（会話文）の内部には出現しない（候補外の地の文にのみ出現、瓶詰地獄13候補・死後の恋23候補いずれも0件該当）ことを確認しており、選定した51候補の抽出・音声化には影響しない。未定義entity（`&amp;`/`&lt;`/`&gt;`/`&quot;`以外のnamed/numeric entity）は3作品とも検出されなかった。**この外字の存在自体は、F005確立済みの外字/未定義entity検出手順（本文全体を対象とする、候補内外を問わない）を無効化してよい理由にはならない**ため、F009ではF008のように検出手順を丸ごとスキップせず、既存の検出手順を通常どおり有効な状態で適用し、公開直前検査で万一候補内に外字またはentity差分が検出された場合はfail-closedで当該作品を`pending`に留める（QA-F009 No.3参照）。
